## 무엇을 했나

해리가 지적한 세 번째 항목 — "2번 문제가 1번과 떨어져 있어야 함"(`REV-2026-016`) — 을 고쳤다.
한 단에 든 문항 둘이 위쪽에 붙어 있던 것이, 이제 각자 **자기 칸 맨 위**에서 시작한다.

## 앞서 잘못 읽은 것을 바로잡았다

처음엔 실물이 "둘째 문항을 단 맨 아래에 붙인다" 고 봤다. **줄 세는 방법이 틀렸다** —
`linesegarray` 가 없는 문단을 1줄로 세어 단 전체를 21줄로 봤다. 본문은 11.5pt · 줄간격
165% 라 한 줄이 **6.694mm** 이고 단 295.43mm 는 **44줄**이다. 그러면 2번이 시작하는
18줄째는 44줄의 41% — 절반쯤이다.

즉 실물은 **단을 균등하게 나눠 각 문항을 자기 칸 상단에 둔다.** 편집기도 두 경로 모두
같은 모델이고, Typst 쪽에는 주석으로 그렇게 적혀 있다:

```
CSS   : .slots{grid-template-rows:repeat(n,1fr)}  +  .slot{align-self:start}
Typst : rows: (1fr,) * n     // "단: 높이를 균등 분할해 각 문항을 자기 칸 상단에 고정"
```

## 어떻게 고쳤나 — 선지 배치와 같은 방식

파이썬은 글꼴 실측을 못 한다. 선지 배치(`layoutResolved`)를 편집기가 정해 보내는 것과
같은 이유로, **문항 높이도 편집기가 재서 보낸다.**

- `measureProblemHeights()` (편집기) — 문항마다 렌더 높이(mm)를 잰다. 미리보기 모드와
  무관하게 **화면 밖에 따로 그려서** 재므로 '이 문항' 모드에서도 된다. 30문항 26ms.
- `hwpxPayload()` 가 `heightMm` 으로 싣는다.
- `pad_lines()` (변환기) — `칸 높이 − 문항 높이` 를 빈 문단 수로 바꾼다.
- `template.read_body_line_mm()` — 한 줄 높이를 **틀에서 읽는다**(박아 두면 틀을 바꿀 때
  어긋난다). 단 높이는 편집기 Typst 정본과 같은 상수를 쓴다(`COL_H_FIRST_MM` 295.43 ·
  `COL_H_NEXT_MM` 319.90 = `BOT - ruleY - 4.5`).

## 되돌리지 말 것

- ⚠️ **높이가 없으면 벌리지 않는다.** CLI·손으로 쓴 JSON 은 예전처럼 동작한다. 어림으로
  넣으면 하나만 많아도 둘째 문항이 다음 단으로 밀려 배치가 통째로 어긋난다 —
  없는 것보다 나쁘다.
- ⚠️ **내림으로 자르고, `emit_problem()` 이 늘 붙이는 빈 문단 한 줄을 뺀다.** 올림하거나
  그 한 줄을 잊으면 칸을 넘긴다(칸마다 한 줄씩 넉넉해지는 것을 실제로 겪었다).
- ⚠️ **단의 마지막 문항 뒤는 벌리지 않는다.** 벌리면 그 단이 넘친다.
- ⚠️ `measureProblemHeights()` 는 `.slots` 의 균등 분할(`1fr`)을 **꺼야** 한다. 켜 두면
  칸 높이가 나오지 재려는 문항 높이가 나오지 않는다.
- ⚠️ 편집기의 `RULE1`·`RULEN`·`BOT`·`SPEC.perCol` 이 바뀌면 변환기 상수도 함께 고칠 것.

## 검증

- `test_page_layout.py` 에 '문항 간격' 6건 추가 — 높이 있음/없음, 단 경계, 벌린 양이
  `칸 − 문항` 과 같은지, 칸을 넘기지 않는지(147.2mm ≤ 147.7mm), 문항이 칸보다 크면
  안 벌리는지. **일부러 되돌려 빨간불도 확인**했고 그 확인을 검사 안에 넣었다.

  147.7mm 와 맞는다. 실물은 16~19개를 벌리고 우리는 17~21개(문항 내용이 다르다).
- **실물 한글에서 열린다**(`npm run test:hwpx-opens`).

## 검토 요청

- **눈으로 봐 주면 좋겠다.** 이 변경은 '열리는가' 를 넘어 '보기 좋은가' 의 문제라,
  실물 한글에서 1~2쪽을 실제로 보고 문항 둘이 단에 고르게 놓였는지 확인해 주면 좋겠다.
- 편집기 미리보기는 **웹폰트**로 그린다. 로컬 서버가 실물 시험 글꼴을 내려 주면 한글과
  가깝지만, 글꼴이 없으면 잰 높이가 한글의 실제 높이와 달라질 수 있다. 지금은 내보내기
  자체가 로컬 서버를 요구하므로 글꼴도 함께 오지만, 나중에 시험지를 브라우저로 옮기면
  이 전제를 다시 볼 것.
