## 변경 내용

첨부된 국어 시험지 원본을 렌더·확인해, 실제 시험지에서 반복되는
`<보기>/<자료>/<학습 활동>`의 **설명문+표가 한 테두리 안에 있는** 형식을 우선 보완했다.
`index.html`의 `bogi` 블록은 선택적으로 `rows`와 `header`를 저장·정규화하고, 편집기에서
`상자 안에 표 넣기`로 행·열·머리글을 편집한다. 기존 `text`/`label`만 가진 보기는 빈 표를
추가하지 않는다. 독립 표와 보기 안 표는 같은 안전한 HTML 렌더 함수를 공유한다.

사용자 제보에 따라 `mock-exam-editor.html`의 2쪽 이후 `수학 영역` 제목 y 좌표를
24mm에서 17.5mm로 올렸다. 왼쪽 전체 시험지 미리보기와 Typst 내보내기 프레임을 같은 값으로
바꿔, 제목 줄상자가 35.01mm 가로 괘선과 겹치지 않게 했다.

원본에서 본 나머지 유형(긴 지문/시·고전시가, 문항 묶음, 대화·온라인 매체, 사진·도표, 밑줄·
범위 표기)은 기존 지문·대화·이미지·마크업 블록으로 커버된다. 복합 지면을 자동으로 재조판하는
기능은 이번 범위에 넣지 않았고, 현재는 이미지 블록으로 원형 보존이 가능하다.

## 위험과 검토 요청

보기 표는 새 선택 기능이므로 구형 JSON 호환성과 표 셀의 XSS 차단을 특히 검토해 달라.
현재 행은 최대 20개, 열은 최대 10개, 셀은 최대 300자로 정규화한다. 모의고사 수정은 2쪽 이후
제목 위치만 바꾸며 페이지 번호·본문·첫 쪽 머리말 좌표는 건드리지 않았다. 실제 상용 글꼴이
설치된 환경에서 Typst PDF 한 장을 눈으로 비교하면 가장 좋다.

## 검증

- 실행한 명령 또는 수동 절차:
  - `python3 serve.py --port 8787` 후 로컬 `regression-test.html` 실행
  - `npm run test:mock-layout`
  - `npm run check:fast`
  - `npm run test:visual`
  - `git diff --check`
- 결과:
  - 브라우저 회귀 `90 / 90 통과`.
  - 새 보기 내 표 렌더·구형 보기 호환·표 셀 XSS·보기 표만 있는 문제집의 병합 보존을 확인.
  - 모의고사 레이아웃 검사는 HTML/Typst의 2쪽 이후 제목 y 값 일치와 제목 줄상자 하단이
    가로 괘선보다 위에 있음을 확인.
  - 레이아웃 검사 조건을 의도적으로 반대로 바꾸자
    `2p+ 수학 영역의 줄상자가 가로 괘선과 겹치지 않아야 합니다` assertion으로 실패했고,
    원복 뒤 통과.
  - 빠른 검사 및 인쇄 시각 회귀 4종 모두 통과.
- 아직 실행하지 못한 검증과 이유:
  - 상용 평가원 글꼴이 설치된 Typst PDF의 육안 대조. 이 환경에서는 HTML 미리보기와
    Typst 좌표 일치·기존 인쇄 시각 기준본으로 확인했다.

## 다음 검토자에게

`index.html`의 `normBlock(bogi)`, 보기 블록 편집 UI, `tableHTML()`과
`regression-test.html`의 국어 보기 검사부터 확인하면 된다. 모의고사 쪽은
`mock-exam-editor.html`의 `renderPreview()`와 `TYPST_FRAME`의 2p+ `area` y 값이
둘 다 17.5mm인지, `scripts/mock-exam-layout.test.mjs`가 그 동기화와 괘선 여백을
잡는지 검토해 달라. 사용자 첨부 HWP/PDF 원본은 작업 트리에 포함하거나 커밋하지 않았다.
