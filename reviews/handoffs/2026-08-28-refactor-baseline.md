## 변경 내용

구조 분리 전 기준점을 고정했다. `test-fixtures/refactor-baseline/`에 사용자 데이터와
분리된 문제집 JSON 4종(수학 수식, 국어 지문, 이미지, 긴 인쇄 문항)을 추가했다. 이 파일은
자동으로 가져오거나 저장되지 않으며, 이후 리팩터링 단계에서 편집·미리보기·인쇄 결과를
비교하는 입력으로만 사용한다.

시작 시점의 현재 브랜치는 `main`, 마지막 커밋은 `7cd177e chore: deploy quota durable object`다.
상용화·보안 관련 작업을 포함한 기존 미커밋 변경이 이미 있으므로, 이후 분리 작업은 그 변경을
되돌리거나 덮어쓰지 않은 상태에서 진행해야 한다.

## 위험과 검토 요청

기준 샘플은 실제 Firebase 업로드 경로나 실물 프린터 출력까지 자동 검증하지 않는다. 이미지
샘플은 외부 자원 없이 검증할 수 있도록 작은 PNG 데이터 URL을 사용했다. Firebase 동기화와
Storage는 전용 테스트 계정에서 별도 확인한다.

## 검증

- 실행한 명령 또는 수동 절차: 4개 JSON 파싱 및 문제 수·과목 확인, `npm run check:static`,
  `git diff --check`, 로컬 `regression-test.html` 실행.
- 결과: JSON 4개 모두 유효(수학 2문항, 국어 2문항, 이미지 1문항, 인쇄 1문항), 정적 검사 통과,
  회귀 검사 `83 / 83 통과`.
- 아직 실행하지 못한 검증과 이유: 기준 JSON을 실제 Firebase 테스트 계정에 가져와 동기화하는
  검증은 사용자 계정 데이터와 분리된 테스트 계정이 필요한 다음 단계로 남겼다.
