## 왜 했나 — 지금까지 조건을 못 지키고 있었다

한컴 수식 규격서의 저작권 조항은 이 문장을 **제품 내 유저인터페이스, 매뉴얼, 도움말 및
소스에 모두** 기재하라고 요구한다:

> 본 제품은 한글과컴퓨터의 한글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.

전수 검색해 보니 **소스(`hwpx-engine.js` · `tex_to_hwp.py`)와 문서(`docs/HWP-SPEC.md`)에만**
있었고 **화면 넷에는 하나도 없었다.** HWPX 내보내기를 제품 기능으로 쓰는 이상 조건 미이행
상태였다. `CLAUDE.md` 도 "화면·매뉴얼에는 아직이다 — 상용화 전에 반드시" 라고 적어 두고
있었다.

사실과 근거(`docs/HWP-SPEC.md`)를 적어** 나중에 "군더더기" 로 지워지지 않게 했다.

## ⚠️ 모의고사 편집기에서 한 번 잘렸다 — 흐름 밖으로 옮겼다

처음에는 `</main>` 뒤에 평범한 `<footer>` 를 두었는데, **1280×800 에서 고지가 25px 잘려
보이지 않았다.** 이 앱은 `body{overflow:hidden}` 에 `.panes{height:calc(100% - 60px)}` 로
화면에 딱 맞춰 놓아서, 흐름에 무엇을 더하면 **스크롤이 아니라 잘린다.**
잘리는 고지는 조건을 못 지킨다.

⚠️ **대조군으로 확인했다** — 푸터를 뺐을 때와 넣었을 때를 세 뷰포트에서 쟀다:

```
              푸터 없음 → 있음
1280×800        0  →  25     ← 내가 만든 회귀
 768×1024      81  → 106     ← 81 은 원래 있던 것
 375×812      456  → 494     ← 456 은 원래 있던 것
```

**고침**: `position:fixed; right:0; bottom:0` + `pointer-events:none`. 자리를 차지하지 않아
넘침이 **다시 0** 이 되고, 조작을 가로채지도 않는다. 네 뷰포트(1280×800 · 1440×720 ·
768×1024 · 375×812)에서 `isVisible()==true` 이고 화면 안에 들어온다. 덮는 자리는 빈 편집
영역(`DIV.ed`)이며 그 아래에 조작 요소가 없음을 확인했다.

⚠️ **근본 원인은 따로 이슈로 냈다 — `REV-2026-062`.** `.panes{height:calc(100% - 60px)}` 는
`REV-2026-028` 이 `index.html` 에서 걷어낸 **바로 그 상수 빼기**인데 이 화면에는 남아 있다.
라이선스 고지 작업에 앱 핵심 레이아웃 변경을 섞으면 회귀가 났을 때 원인을 못 가르므로,
이번에는 우회하고 근본 수정은 별도로 남겼다.

## 검사

`check:static` 에 **여섯 곳**을 대조하는 검사를 넣었다 — 화면 넷 + `hwpx-engine.js` +
`tex_to_hwp.py`. 조항이 "모두" 를 요구하므로 한 곳만 빠져도 빨간불이다.

## 검증

- **깨보기 여섯, 전부 빨간불**: 여섯 파일에서 각각 그 문장만 지우고 돌려, 해당 파일
  이름과 함께 실패하는 것을 하나씩 확인했다.
- **화면으로 확인**(검사만 믿지 않는다): 다섯 조합을 띄워 실제로 보이는지 쟀다 —
  `index`(1280·**375**) · `mock`(1280) · `document`(1280) · `legal`(1280).
  전부 `visible:true`, **가로 넘침 없음**(`inViewport:true`), 페이지 오류 0.
  ⚠️ **탐침이 두 번 나를 속였다 — 둘 다 제품이 아니라 탐침 문제였다.**
  ① `document-editor.html` 을 `found:false` 로 봤다: '자식 없는 요소' 만 찾았는데 그 푸터는
     `<br>` 을 갖는다 → 텍스트 노드 순회로 다시 재어 확인.
  ② 모의고사의 고정 푸터를 `보임:false` 로 봤다: **`offsetParent` 는 `position:fixed` 요소에
     항상 `null`** 이고, `pointer-events:none` 이라 `elementFromPoint` 도 뒤 요소를 준다
     → `isVisible()` 과 계산된 스타일로 다시 재어 확인.
- `npm run check:fast` **종료코드 0** · 회귀 154/154 · `test:library-ui` 13건.
- 원격 push·배포 없음.
