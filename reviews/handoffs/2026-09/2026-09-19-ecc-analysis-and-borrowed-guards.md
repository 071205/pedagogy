## 무엇을 했나

사용자가 [ECC](https://github.com/affaan-m/ECC)(MIT · "agent harness performance optimization
system")를 두고 "통째로 말고 뜯어 보고 필요한 것만" 을 요청했다. 저장소를 받아 읽고,
**코드는 한 줄도 옮기지 않고 기법 셋만** 우리 방식으로 구현했다. `python-hwpx` 에 대해
내린 것과 같은 결론이다 — 사본은 갈라지고, 라이선스 의무가 따라온다.

## 통째로 넣지 않은 이유 (측정값)

| 항목 | 값 |
|---|---|
| 규모 | 파일 3,753개 · 92MB · 에이전트 68 · 스킬 292 · 명령 94 · 훅 스크립트 24 |
| **매 세션 실리는 설명** | 스킬 20,238 + 에이전트 3,812 + 명령 2,528 ≈ **26,600 토큰** |
| 훅이 바깥으로 보내는 데이터 | **없다** — 훅이 부르는 24개를 전수 확인했고 네트워크 호출은 `127.0.0.1`(자기 대시보드) 하나뿐 |
| Stop 훅의 포매터(`--write`) | 이 저장소에서는 **아무 일도 안 한다**(biome/prettier 설정이 있어야 돈다) |

품질 문제가 아니라 **맞음새** 문제다. `docs/DEV-TOKEN-ROADMAP.md` 의 목표가 에이전트 비용
절감인데 26,600 토큰을 매 세션 더하는 것은 반대 방향이고, DEV-5 는 이미 "근거 없는 구조
변경은 안 받는다" 로 끝났다. 무엇보다 ECC 가 파는 것(워크플로 규약·메모리·검토)은 이 저장소가
**실제 실패에서 뽑아** 이미 갖고 있고, 일반 규칙이 측정된 규칙을 덮으면 그게 회귀다.

## 가져온 기법 셋

| ECC 의 것 | 우리 것 | 왜 이 모양인가 |
|---|---|---|
| `gateguard-fact-force` — 편집 전 사실 강제(수입 목록·API·스키마) | `.claude/hooks/pair-guard.mjs` | 여기의 1번 실패는 "수입 목록을 몰라서" 가 아니라 **"짝을 한쪽만 고쳐서"** 다. 일반적인 사실 넷 대신 **그 파일의 짝을 이름으로** 댄다 |
| `pre-bash-commit-quality` — 커밋 전 점검 | `.claude/hooks/git-add-guard.mjs` | 오늘 실제로 `worker/index.js` 한 파일에 갈래 둘이 섞여 있었다. `git add -A`·`commit -a` 에만 반응한다 |
| 반복 절차를 스킬로 포장한다는 발상 | `.claude/skills/hwpx-element/` | ①~④ 절차를 이미 세 번 밟았고(쪽나눔·각주·머리말) 둘이 남았다 |

`config-protection`(포매터 설정 보호)은 여기 포매터가 없어 해당 없음. 스킬 292개는
angular·android·clickhouse 같은 일반 주제라 이 도메인에서는 우리 문서가 더 깊다.

## 설계에서 지킨 것

⚠️ **두 훅 모두 막지 않는다. 알리고 언제나 exit 0 이다.** 판정은 검사가 한다 — 훅은 그
빨간불을 10분 뒤가 아니라 편집하는 순간에 보이게 할 뿐이다. 막는 훅으로 바꾸지 말 것:
`REV-2026-023`(편의 기능이 본체를 멈춘 사고)과 같은 자리다.
⚠️ **`git-add-guard` 는 heredoc 본문을 보지 않는다.** 이 저장소는 커밋 메시지를 heredoc 으로
쓰므로, 메시지에 적힌 `git add -A` 에 반응하면 양치기 소년이 된다. 자기검사에 그 경우가 둘 있다.
⚠️ **짝 표는 한 자리다**(`PAIRS`). 늘릴 때 다른 곳에 베끼지 말 것.

## 검증

- `npm run check:hooks`(새 항목, `check:fast` 맨 앞 묶음) — 짝 표 18줄 경로 확인 + 가드 자기검사 10건.
- **깨보기**: 짝 표의 경로를 없는 이름으로 바꾸니 `exit 1` 로 빨간불, 되돌리니 통과.
  `git add -A` 가드는 heredoc 안 글자에 반응하지 않는 것을 자기검사가 지킨다.
- 훅 본체 실동작 확인 — 짝 있는 파일(알림 뜸) · 짝 없는 파일(조용) · 망가진 입력(조용히 exit 0).
- `npm run check:static` · `npm run check:review-hygiene` 통과.
