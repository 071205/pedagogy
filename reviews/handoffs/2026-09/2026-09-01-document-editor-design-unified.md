## 변경 내용

`document-editor.html` 이 본체(`index.html`)와 **완전히 다른 디자인 시스템**을 쓰고 있었다.
본체에서 넘어오면 화면이 통째로 바뀌어 다른 사이트처럼 보였다.

| | 고치기 전 | 고친 뒤 |
|---|---|---|
| 토큰 이름 | `--paper`·`--ink`·`--muted`·`--line` | 본체와 같은 `--surface-*`·`--text-*`·`--border` |
| 글꼴 | `system-ui` | Pretendard (본체와 같은 link + SRI) |
| 상단 바 | 로고 + 로그인 둘뿐 | 로고·내비(문제집·모의고사·AI 문서)·테마·로그인 |
| 테마 전환 | 없음 | 있음 — **본체와 같은 저장 키(`PM_THEME`)** |
| 푸터 | 없음 | 있음 |
| 버튼·카드·모서리 | 자기 값 | 본체 치수(높이 34px·radius 10px 등) |

⚠️ **테마 저장 키를 맞춘 것이 중요하다.** 키가 다르면 본체에서 어둡게 해 두고 넘어왔을 때
갑자기 밝아진다. 실제로 어둡게 설정하고 넘어가 확인했다.

베타 안내 문구가 "표·이미지는 다음 단계" 라고 옛 내용을 말하고 있어 함께 고쳤다.

## 고치다 두 번 깨뜨렸다 (남겨 둘 교훈)

1. **주석 안에 `<style>` 을 글자로 썼다.** HTML 파서가 그것을 진짜 여는 태그로 읽어,
   내가 넣은 CSS 가 통째로 주석 안으로 들어갔다 — 화면이 스타일 없이 렌더됐다.
   지금 그 자리 주석에 "여기에 style 여는 태그를 글자로 쓰지 말 것" 이라고 적어 뒀다.
2. **복구하면서 `<head>` 의 script 태그 4개를 날렸다**(KaTeX·Firebase 2개·service-config).
   화면은 멀쩡해 보였는데 **수식이 빨갛게 렌더 실패**로 나와서 알았다.
   `git show HEAD:` 로 원본에서 SRI 해시째 되살렸다.

둘 다 **화면을 보지 않았으면 몰랐을 것**이다. CSS 는 문법 검사를 통과해도 적용이 안 될
수 있고, 스크립트가 사라져도 페이지는 그려진다.

## 재발 방지 — `scripts/check-shared-design.mjs`

이 저장소는 빌드 단계가 없어 각 `.html` 이 자기 CSS 를 통째로 안고 있다. **토큰을 베끼는
것 말고 방법이 없고, 베낀 것은 반드시 갈라진다.** 두 파일의 `:root` 토큰 이름과 값,
그리고 테마 저장 키가 같은지 본다. `check:static` 에 걸어 CI 에서 항상 돈다.

본체에만 있어도 되는 것(`--print-*`·`--sidebar-w`·`--col-gap-mm`·본문 세리프)은 예외로 두었다 —
문항 편집·인쇄 전용이라 문서 화면이 쓸 일이 없다.

**레이아웃까지 같게 만들려는 검사가 아니다.** 두 화면은 하는 일이 다르므로 구조는 달라도
된다. 같아야 하는 것은 '같은 사이트로 보이는가' 를 결정하는 토큰이다.

## 위험과 검토 요청

- 상단 바의 `모의고사` 링크를 `index.html#mock` 으로 걸었다. 본체는 모의고사를 버튼으로
  전환하는 구조라(iframe) **이 해시를 처리하지 않을 수 있다** — 그러면 그냥 본체 첫 화면으로
  간다. 동작을 봐 달라.
- 미리보기 종이(`.preview`)는 흰 배경·검은 글씨로 **고정**했다. 인쇄물을 보여 주는 곳이라
  어두운 테마에서도 종이처럼 보이는 편이 맞다고 판단했다.

## 검증

- `node scripts/check-shared-design.mjs` — 토큰 22개·테마 키 일치.
- **일부러 깨뜨려 확인**(둘 다 원복 후 재통과): 토큰 값 하나를 어긋냄 → 잡힘.
  테마 키를 바꿈 → 잡힘.
- **화면으로 확인** — 밝은 테마·어두운 테마 양쪽에서 상단 바·카드·버튼·표·상자가
  본체와 같은 모양으로 그려지고, 수식이 정상 렌더되는 것을 봤다.
- `npm run check:fast` 통과 · `npm run test:visual` 4건 통과.
