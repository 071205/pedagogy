첫 분리에서 저장·동기화·인증 전체, ESM 전환과 프레임워크 도입을 제외했다.

후보 A는 이후 OPS 서비스 AI 작업과 맞닿아 있으나, 실제 요청과 결과 반영까지 함께 옮기면 상태 경계가 넓어진다.

이력 기반 수정 빈도는 확정하지 못했다. `git log -S`가 열린 REV-2026-074의 깨진 ref에서
`fatal: bad object`로 중단된다. 이 단계에서 Git 내부 파일을 고치지 않고 현 소스·2026-09 인계 근거만 사용했다.
REV-2026-075의 실계정 로그인 신고도 재현하지 않았으며 상태를 바꾸지 않았다.
