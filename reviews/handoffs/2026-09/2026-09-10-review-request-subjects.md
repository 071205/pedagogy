## 1. ⚠️ 먼저 봐 달라 — 내가 뒤집은 것

`docs/ENGLISH-SUBJECT-DESIGN.md` §② 는 **"실물 어휘 문항의 네모는 두 낱말이 세로로 쌓인
상자다"** 라고 적고 있었다. **실물에서 틀렸다** — 2009 수능의 네모 여섯 개가 전부 높이
**5.2mm(한 줄)** 이고 두 낱말은 ` / ` 로 나란하다. 상자는 글자 테두리도 표도 아닌
**`<hp:rect>` 개체를 글 위에 얹은 것**이다(테두리 0.198mm).

즉 **② 에 필요한 코드는 없었고**, 진짜 빠진 것은 짝 선지였다.

**검토 요청**: 내가 잰 방법이 맞나? 재현은 아래 한 줄이다.

```bash
python3 - <<'P'
import zipfile,re
x=zipfile.ZipFile('2009학년도 수능 영어 문제.hwpx').read('Contents/section0.xml').decode()
i=x.find('hesitancy')
for m in re.finditer(r'<hp:rect\b.*?</hp:rect>', x[i-6000:i+3000], re.S):
    s=re.search(r'<hp:sz width="(\d+)"[^>]*height="(\d+)"', m.group(0))
    if s: print(round(int(s.group(1))/7200*25.4,2),'×',round(int(s.group(2))/7200*25.4,2),'mm')
P
```

## 2. 내가 판단으로 정한 것 (다르게 볼 수 있다)

| 판단 | 왜 | 다르게 본다면 |
|---|---|---|
| 탐구 **표**는 과목으로 가른다(0.87em) | 두 실물이 9.5~10.0pt 로 **일치** | 범위의 큰 쪽을 골랐다. 9.5(0.83)가 맞나? |
| 탐구 **상자**는 과목으로 **강제하지 않는다** | 사회·문화 9.5 vs 화학Ⅰ 11.5 로 **어긋난다** — 하나로 정하면 하나는 틀린다 | 그래도 기본값을 주는 게 나은가? |
| 짝 선지 칸 가름표를 **`\|`** 로 | `/` 는 낱말 안(`hesitancy / consistency`)에 이미 쓰인다 | 더 나은 표기가 있나 |
| `……`·`(A)(B)(C)` 를 **렌더가 붙인다** | 출처 `–`, 각주 `*`, 안내문 `∙` 과 같은 규칙 | |
| 칸 합치기 UI 를 **켤 때만** 보여 준다 | 실물에서 7건뿐이라 늘 보이면 방해다 | |
| mhchem 을 **넣었다**(스크립트 하나 추가) | 화학식 440개 · `\ce` 하나만 없었다 | 부팅 비용을 재지 않았다(§4) |

## 3. 공격 지점 — 내가 검토자라면 여기를 친다

### (a) 평행 배열이 **셋**이 됐다
`table` 이 `rows`(글) · `images`(그림) · `spans`(합치기) 를 나란히 든다.
- **행 추가/삭제가 셋을 함께 움직이는가?** `index.html` 의 `addR.onclick` 과 행 삭제
  `rm.onclick` 을 볼 것. 하나라도 빠지면 다음 행의 그림·합치기가 한 칸씩 밀린다.
- **열 추가는 `rows` 만 늘린다** — `images`/`spans` 는 접근 시점에 채운다. 이게 안전한가?
- ⚠️ 셋이 넷이 되면 이 방식이 버티나? (다음에 각주·정렬이 오면)

### (b) `blockImageSlots()` 가 유일한 자리 목록인가
표 칸 그림을 여기 안 넣으면 `REV-2026-019`(남이 쓰는 파일 삭제)·`-020`(base64 가 1MB
한도 초과)이 **재현된다**. 넣었지만, **수집·감지·이관·저장 전 판정 네 곳이 전부** 그것을
지나는지 확인해 달라.

### (c) 합치기의 경계값
- `[999,999]` 는 정규화가 20/30 으로 조이고 렌더가 남은 칸 수로 한 번 더 조인다.
  그 결과 **행이 통째로 빈 `<tr>`** 이 될 수 있다(내가 확인한 값: 행합 `[2,0]`).
  이게 허용 가능한 결과인가, 아니면 더 막아야 하나?
- 겹치는 합치기(가로2 와 세로2 가 같은 칸을 노리는 경우)의 결과를 정하지 않았다.
  지금은 **먼저 만난 칸이 이긴다**(`taken` 순회 순서). 명세로 굳혀야 하나?

### (d) 인쇄 경로
- 짝 선지는 `fitPrintDoc` 의 넘침 보정 선택자에 **넣었다**.
- **표는 넣지 않았다** — 표에 그림·합치기가 생겨 가로로 넘칠 여지가 커졌는데,
  `fitPrintDoc` 이 표를 축소 대상으로 보는지 **나는 확인하지 않았다.** 여기가 제일
  의심스럽다.

### (e) mhchem 순서
KaTeX **뒤**, auto-render **앞**. `check:static` 이 순서·SRI 를, `regression-test.html` 이
**실제 렌더**를 본다(해시가 틀리면 조용히 차단되므로). 두 검사가 충분한가?

## 4. 내가 확인하지 못한 것 (정직하게)

1. **mhchem 이 부팅 성능에 주는 영향을 재지 않았다.** 33KB · `defer` 지만,
   이 저장소는 렌더 차단으로 2,010ms 를 잃은 적이 있다(2026-08-25 6차).
2. **탐구 실물이 과목당 한 부씩뿐이다.** 물리·생명·지구과학, 생활과 윤리·한국지리 등은
   값이 다를 수 있다. 일반화하지 않았다.
3. **한글(HWPX) 내보내기 경로는 안 봤다.** 이번 것들은 문제집 편집기(브라우저 인쇄)만
   손댔다. 모의고사 HWPX 는 수학 틀 전용이라 무관하다고 판단했는데, **그 판단이 맞나?**
4. **실제 기기(사파리·아이패드)에서 안 봤다.** 크로미움만이다.
5. `REV-2026-074`(아이콘 재발)·`REV-2026-075`(AI 문서 로그인)는 **여전히 열려 있다.**
   후자는 가설 둘을 지웠지만 로그인 세션이 있어야 더 갈 수 있다.
