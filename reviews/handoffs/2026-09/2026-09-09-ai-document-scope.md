# 변경 인계 — AI 문서를 화면에서 빼고 코드로 남김

- 작성자: `Claude`
- 상태: `ready-for-review`
- 영향 영역: `index | docs | tests`
- 관련 이슈: `REV-2026-075` (open · 새로 등록)

## 결정 (해리)

`index.html` 에서 **AI 문서로 가는 링크를 없앴다.** 파일·엔진·검사는 **그대로 둔다.**

이유는 [`docs/AI-DOCUMENT-SCOPE.md`](../../../docs/AI-DOCUMENT-SCOPE.md) 에 적었다. 요지는
**원래 기획 의도가 이미 이뤄져 있었다**는 것이다 — "AI 에게 부탁해 한글로 조판하고 그것을
모의고사 조판에 응용한다" 는 목적은 `hwpx-engine.js` 를 모의고사 한글 내보내기가 그대로
쓰는 것으로 달성됐고, **별도 화면은 그 목적에 필요하지 않았다.** 오히려 라이브러리와 같은
자리에 범용 문서 도구가 있어 "이게 무슨 프로그램인가" 가 흐려졌다.

⚠️ **지우는 것과 입구를 빼는 것은 다르다.** 주소로 직접 열면 지금도 동작한다.

## 입구가 **두 곳**이었다

상단 바(`1493`)와 왼쪽 레일(`1546`) 둘 다에 있었다. `-097` 에서 레일로 옮기면서 상단 것을
지우지 않아 중복돼 있었고, 그래서 `test:cross` 의 상단 바 검사가 계속 초록불이었다.
둘 다 없앴다.

## 검사가 결정을 지킨다 — **두 방향으로**

`check:static` 이 함께 본다:
- `index.html` 이 **다시 링크하지 않는지**
- `serve.py` 의 `STATIC` 에서 `document-editor.html`·`hwpx-engine.js`·`hwpx-document.js` 가
  **빠지지 않았는지**

⚠️ 한쪽만 보면 "입구를 뺀다" 가 어느새 "지운다" 가 된다. 엔진이 사라지면 **모의고사
한글 내보내기가 함께 죽는다.**

## ⚠️ 교차 검사의 '붙어 있는가' 를 옮겼다 — 그리고 그게 헛돌고 있었다

`REV-2026-063`(보이지 않는 채움에 기댄 레이아웃)을 잡던 검사는 브랜드↔모의고사 →
브랜드↔AI 문서로 이미 한 번 옮겨졌고, 이제 그 짝마저 사라졌다. **지우지 않고** 지금 탐색
자리인 **레일의 두 항목 간격**을 재게 옮겼다(세로·가로 배치를 함께 본다).

그 과정에서 두 가지를 발견했다.

1. **레일은 라이브러리 화면에만 있다.** 다른 화면에서 재면 사각형이 0×0 이라 간격이 0 이
   되어 **무엇을 깨뜨려도 통과한다.** 자기검사(`BREAKS`)가 그것을 잡았다 — 고장을 심었는데
   초록불이었다.
2. 고치려고 `showLibrary()` 를 불렀더니 **앱 상태가 바뀌어 뒤 검사 여섯이 무너졌다**
   (실패 1건 → 7건). 지금은 화면 전환 없이 **인라인 `display` 만 잠깐 켰다 되돌려** 잰다.

고장 주입도 함께 옮겼다. **안 옮겼으면 자기검사가 없는 probe 를 찾다 실패하고 진짜 회귀는
아무도 안 보게 된다.**

## 열어 둔 이슈 — `REV-2026-075`

"AI 문서에 들어갔다 나오면 로그인이 안 된다"(해리 실사용). **재현 절차를 아직 못 만들었다.**
추측 셋을 적었지만 확인 전이라고 명시했다.
⚠️ **입구를 뺐다고 결함이 사라지지 않는다** — 주소로 직접 여는 사람은 여전히 만난다.
그래서 닫지 않았다.

  환경 연기 검사 통과(경고 2건은 의도된 CDN 차단).
- `npm run check:static` — 새 두 방향 계약 포함 통과.
- `npm run check:fast` 통과.
