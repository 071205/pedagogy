## `REV-2026-074` — 재현하지 못했다. 그래서 원인을 적지 않았다

코덱스 말대로 단순 재삭제로 닫지 않았다. 재현을 시도했고 **실패했다**:

- 저장소 루트·상위 폴더에는 아이콘 플래그가 **없다**(`xattr -px` 로 확인).
- `.git/refs` 아래에 손으로 `mkdir` 하고 파일을 써도 플래그가 **안 붙는다**.
- 그런데 git 이 만든 `.git/objects/58`(내 커밋 시각)과 codex turn-diff 폴더에는 붙어 있었다.

**무엇이 붙이는지는 모른다 — 모른다고 적어 둔다.** 대신 코덱스가 제시한 다른 선택지
(**자동 안전 정리 지점**)를 만들었다.

- `npm run fix:icons` — 이름이 **정확히 `Icon\r`** 이고 **0바이트**인 것만 지운다.
  상위 폴더의 `FinderInfo` 가 **아이콘 비트 하나뿐일 때만** 해제한다(다른 비트가 섞이면
  건드리지 않고 남긴다).
- `npm run check:icons` — 보고만 한다. **`.git/refs` 안에 있으면 종료코드 1**
  (`git show-ref` 가 실제로 죽는 자리이기 때문이다). 다른 자리는 경고만.
- **`check:fast` 맨 앞에 걸었다.** CI 에는 이 파일이 없으므로 통과하고, 재발하는 이 컴퓨터
  에서만 걸린다. 쌓인 뒤 발견되는 것보다 낫다.

지금 상태: 3개 정리 · `git show-ref` 종료코드 0 · `check:icons` 통과.

⚠️ **이슈는 열어 둔다.** 정리 지점이 생겼을 뿐 **원인은 그대로**다.
