## 변경 내용

`index.html`의 라이브러리 전용 액션 네 개를 높이 40px, 곡률 16px로 국소 보정하고 주 액션에
약한 깊이감을 더했다. 폴더 칩은 검색과 도구 사이의 유연한 필터 트레이로 옮겨 데스크톱의
빈 공간을 사용하고, 1023px 이하에서는 검색·도구 아래의 독립 행으로 내려가게 했다.
상단 `AI 문서 β`의 음수 왼쪽 여백도 제거해 `모의고사`와 겹치지 않게 했다.

다중 모의고사는 현재 단일 `MOCK_DRAFT_V1` 저장 구조에서 화면만 바꾸면 데이터 안전을
보장할 수 없어 구현하지 않았다. 대신 `docs/MOCK-LIBRARY-DESIGN.md`에 정보 구조, 별도 저장
모델, 구형 임시본의 멱등 이전, 단계별 구현·검증 완료 조건을 확정했다.

## 위험과 검토 요청

폴더 수가 많아도 칩을 자르지 않고 wrap하는지, 1194px에서 검색·폴더·도구가 자연스럽게
배치되는지, 768/375px에서 폴더 트레이가 독립 행으로 내려가는지 확인해 달라. 다중 모의고사
후속 구현에서는 구형 키를 새 저장 확인 전에 삭제하지 말아야 한다.

## 검증

- `npm run check:fast` — 통과. Chromium 교차 환경, 정적·접근성 계약 26개, 브라우저 회귀
  154/154, 리뷰 계약, 라이브러리 UI 13개가 모두 통과했다. Python `lxml`이 없어 HWPX의
  Python 대조만 기존 정책대로 건너뛰었으며 이번 CSS/문서 변경과 무관하다.
- 별도 Chromium 실측 — 1194×834, 768×1024, 375×812 모두 가로 넘침 0, 액션 버튼 곡률
  16px, 상단 두 도구 사이 8px, 폴더가 `.lib-bar` 안에 있음을 확인했다. 1194px에서 폴더
  트레이는 검색 오른쪽의 557px를 사용했고 768/375px에서는 독립 행으로 내려갔다.
- 스크린샷 육안 확인 — 맥북과 휴대폰에서 버튼·필터·카드 사이 간격과 줄바꿈을 확인했다.
- `git diff --check` — 통과.
- 아직 실행하지 못한 검증: 실제 Safari/iPad 기기 검사는 이 환경에서 할 수 없다. Chromium
  터치 에뮬레이션과 기존 교차 검사로 대체했으며, 실제 기기 완료로 과장하지 않는다.
