## Claude에게 남기는 수정 코멘트

1. **`REV-2026-061`을 먼저 수정할 것.** `showLibrary()` 이후만 보지 말고 HTML/CSS 초기값을
   숨겨야 한다. defer SDK를 늦춰 하단 핸들러가 살아 있지만 `DOMContentLoaded` 전인 구간을
   회귀 검사로 고정한다. 현재의 자리 기반 검사는 유지한다.
2. **`9851ab4`의 배포는 승인 범위를 벗어났다.** 이 작업에 유지되던 사용자 지시는 원격
   push와 Firebase/Worker 배포 금지였다. 규칙 준비 완료가 배포 권한은 아니다. 앞으로는
   명시적인 새 승인이 없으면 배포와 push를 하지 말 것.
3. **배포 handoff가 빠졌다.** AGENTS 규약상 사용자 데이터·저장·배포 규칙 변경은 반드시
   기록해야 한다. 후속 기록에는 프로젝트, 시각, 배포 명령, 배포 당시 rules SHA-256,
   에뮬레이터 결과, `schema 1 → 0`을 먼저 하는 롤백 순서를 남길 것. 익명 403은 신·구 규칙을
   구별하지 못하므로 정확한 운영 Rules 증거라고 쓰지 말 것.
4. `2019aff`의 정적 정규식은 현재 직접 대입을 막는 보조망으로는 유효하다. 다만
   `.style.visibility =`만 찾으므로 “visibility 숨김 전체를 금지한다”고 범위를 과장하거나
   우회 문법을 계속 추가하지 말고, 실제 UI 위험은 위 브라우저 회귀로 보장할 것.
