## 변경 내용

사용자가 개발 토큰 절감과 서비스 AI 비용 작업을 하나의 레일에서 끝내도록 요청했다.
docs/DEV-TOKEN-ROADMAP.md를 유일한 통합 실행 경로로 만들고 AGENTS.md·INDEX 진입점을 맞췄다.
DEV-1 지도 → DEV-2 경계 설계 → DEV-3 구현 → DEV-4 독립 검토 → DEV-5 효과 확인 후,
OPS-6 배포 준비 → OPS-7 실환경 검증 → OPS-8 표본 분석 → OPS-9 한도 판단 → OPS-10 공급자 필요성 판단으로 이어진다.
모델·추론과 조건부 구현/검토 하위 순서는 통합 표에 명시했다. 이번에는 DEV-0 설계만 완료했다.
기존 Worker·측정 회귀·A/B 승인 결과를 유지하고 AI-COST-ROADMAP.md는 이관표·증거 링크만 남겼다.
이전 두 레일 분리·별도 재개 결정은 이번 사용자 정정으로 대체했다. 제품·검사는 수정하지 않았다.

## 위험과 검토 요청

모든 다음 단계 요청이 통합 현재 위치로 들어가야 한다. 필수 회귀·실패 주입·독립 검토 의무를 유지했다.
파일 분리 자체의 절감률을 보장하지 않고 관측·일회성 비용·분리 보류 조건을 넣었다.
모델 권장은 공식 설명을 참고한 작업 배정이며 Codex 사용량 차이를 실측한 결과가 아니다.
새 제품 수정, 모델 자동 변경, 하위 에이전트, 배포, 실호출은 없다.
OPS-6 준비에는 별도 재개 요청이 필요 없으나 실제 배포·유료 호출에는 구체화된 대상·예산 승인이 필요하다.
승인·환경·데이터 대기를 완료로 오인하지 않으며 공급자 비교·어댑터는 근거가 없으면 유지 결정으로 끝낸다.
