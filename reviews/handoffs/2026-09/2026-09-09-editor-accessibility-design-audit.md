## 변경 요약

- 본문 건너뛰기 링크와 포커스 가능한 `main`을 추가했다.
- 클릭 전용 브랜드·문항 열기·문항 추가를 네이티브 버튼으로 바꿨다.
- 정적 메타 필드와 11종 동적 블록 입력·아이콘 조작에 문맥별 접근 가능한 이름을 붙였다.
- 토스트 결과를 화면낭독기에 전달한다.
- `scripts/check-accessibility.mjs`의 26개 계약과 계약별 자기검사를 `check:static`에 연결했다.
- 재렌더 뒤 문항 포커스를 복원하고 이미지 선택 3종을 네이티브 키보드 조작으로 바꿨다.
- 높이가 다른 상단 버튼을 놓치던 교차 검사 판정을 세로 겹침 기준으로 보정했다.

- `npm run check:static` — 통과(접근성 계약 26개와 계약별 자기검사 포함).
- `A11Y_RED=1 node scripts/check-accessibility.mjs` — 의도대로 실패.
- `npm run check:fast` — 1차 수정 기준 통과(브라우저 회귀 154/154, 라이브러리 UI 13개 포함; `lxml` 미설치 HWPX Python 대조는 기존 정책대로 건너뜀). 독립 검토 후 보완은 아래 정적·교차 검사로 다시 확인했다.
- 브라우저 1194×834, 768×1024, 375×812 — 가로 넘침 0, 가시적 무명 컨트롤 0, 스크립트 오류 0.

- 키보드 — 문항 열기·추가 뒤 포커스 유지, 정답·AI·선지 이미지 선택 Enter 동작 확인.
- `npm run test:cross:fast` — 통과(의도된 CDN 차단 경고 2건). 첫 실행은 외부 KoPub Bold가 3초 안에 오지 않아 1건 실패했으나 즉시 재실행에서 7.83MB 세 굵기와 KaTeX를 모두 확인했다.
