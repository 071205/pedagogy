## 변경 내용

`index.html`의 미리보기·인쇄 CSS에서 KaTeX 루트 크기와 블록 수식의 별도 확대를
`1em`으로 통일했다. 수식 안의 `\\text{}` 한글도 `1em`으로 맞춰 수학 본문과 같은
글자 크기로 조판한다. 국어·영어 지문 상단 안내문(`.psg-head`)은 700에서 500으로
낮춰, 본문과 구분은 유지하되 지나치게 굵지 않게 했다.

## 위험과 검토 요청

KaTeX의 큰 연산자·분수 등 수식 내부의 상대 크기는 KaTeX 기본 조판을 그대로 따른다.
긴 블록 수식이 있는 실제 문제집을 인쇄 미리보기로 한 번 확인해, 이전의 1.08배 확대에
의존해 줄바꿈이 맞던 문항이 없는지만 검토한다.

## 검증

- 실행한 명령 또는 수동 절차: `python3 serve.py --port 8799`로 로컬 서버를 열고
  `regression-test.html` 실행, CSS 선택자·값을 정적 재확인.
- 결과: 회귀 검사 `83 / 83 통과`. 미리보기·인쇄 공통 KaTeX 루트/블록 수식 값은 `1em`,
  지문 안내문 굵기는 `500`으로 확인.
- 아직 실행하지 못한 검증과 이유: 실제 프린터 출력은 장치별 글꼴 렌더링 차이가 있어
  이 환경에서는 수행하지 않았다.
