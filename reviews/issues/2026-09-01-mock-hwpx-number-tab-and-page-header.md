# HWPX 시험지의 문항 번호·쪽 머리말이 실물과 다르다

- ID: `REV-2026-015`
- 날짜: `2026-09-01`
- 보고자: `해리` (사용자 · 실물 한글에서 눈으로 발견)
- 상태: `fixed`
- 심각도: `P1`
- 영향 영역: `server`
- 관련 인계: `HANDOFF-2026-027`

## 요약과 영향

사용자가 내보낸 시험지를 한글에서 열어 보고 세 가지를 지적했다.

1. **문항 번호가 이상하다**
2. **시험지 형식이 2페이지에서 사라진다**
3. **2번 문항이 1번과 떨어져 있어야 한다**

이 이슈는 그중 **1과 2** 를 다룬다. 3은 층위가 다른 문제라 `REV-2026-016` 으로 뗐다.

셋 다 **우리 검사가 전부 초록불이고 한글이 파일을 정상적으로 여는 상태에서** 나왔다.
`npm run check:fast` 도 `npm run test:hwpx-opens` 도 통과했다. 화면을 봐야 보이는 종류다.

## 재현 절차

```bash
python3 experiments/hwp-export/mock_to_hwpx.py \
        experiments/hwp-export/samples/full-exam.json out.hwpx \
        experiments/hwp-export/samples/images
```

만들어진 `out.hwpx` 를 실물 틀(`평가원 수학 양식.hwpx`)과 나란히 뜯어 비교한다.

## 기대 결과 / 실제 결과

실물 틀에서 잰 값과 고치기 전 우리 출력.

| | 실물 틀 | 고치기 전 |
|---|---|---|
| 번호 뒤 | `1.` + **탭**(636) · `10.` + **탭 둘**(132·671) | `1. ` **공백** |
| 쪽나눔 | 4회 | **0회** |
| 이어지는 쪽 머리말 | 2쪽 첫 문단에 `<hp:ctrl><hp:header>` | **없음** |

### 1. 번호 — 공백은 자릿수마다 발문 시작 위치를 어긋나게 한다

실물은 번호와 발문 사이를 **탭 정지점**으로 맞춘다. 한 자리든 두 자리든 발문이 같은
가로 위치에서 시작한다. 우리는 공백 하나를 넣어 `1. 함수…` / `10. 함수…` 의 발문이
글자 폭만큼 어긋났다. 번호 자체는 맞는데 **번호만 삐뚤어 보이는** 증상이 이것이다.

### 2. 2페이지 — 머리말은 masterpage 가 아니라 본문에 있다

`secPr` 도 `masterpage0~3` 도 실물과 **바이트까지 동일**했다. 그래서 처음엔 쪽 설정이
원인이 아니라고 판단했는데, `masterpage1` 이 `type="OPTIONAL_PAGE" pageNumber="1"` 로
**특정 쪽에만** 붙는 것이었다.

실물은 이어지는 쪽 머리말(`수학 영역`)을 **본문 문단 안**에 둔다 — 2쪽 첫 문단
(5번 문항)에 `<hp:ctrl><hp:header>…</hp:header></hp:ctrl>` 두 개가 있고, 3쪽부터는
그것을 물려받는다(8·13·18번 문단에는 없다는 것을 확인했다).

`template.clear_body()` 는 첫 문단만 남기고 나머지를 지운다. 그래서 그 머리말이 통째로
사라졌고, 우리 출력에는 어느 쪽에도 머리말이 없었다. 게다가 쪽나눔을 하나도 내보내지
않아 **머리말을 도로 붙일 자리조차 없었다.**

### 곁가지로 드러난 것 — 선택과목 이름이 2쪽부터 틀렸다

머리말을 되살리자 `set_masthead_elective()` 가 **첫 번째 `수학 영역(…)` 만** 바꾸는 것이
드러났다. 사용자가 미적분을 골라도 표지만 미적분이고 **이어지는 쪽 머리말은 틀에 박힌
`확률과 통계`** 로 인쇄된다. 머리말을 되살리지 않았다면 영영 안 보였을 결함이다.

## 원인

- `mock_to_hwpx.emit_problem()` 이 `prefix=f"{num}. "` — 탭이 아니라 공백.
- `mock_to_hwpx.build()` 이 `columnBreak` 만 내보내고 `pageBreak` 를 내보내지 않았다.
  쪽 경계를 한글의 자동 흐름에 맡겨 편집기 `buildPages()` 와 어긋날 수 있었고,
  머리말을 붙일 문단을 특정할 수 없었다.
- `template.clear_body()` 가 머리말을 지우는데 아무도 떠 두지 않았다.
- `template.set_masthead_elective()` 가 구역마다 첫 일치만 고쳤다.

## 수정

- `pedagogy_hwpx.XmlNode.to_xml()` 추가 — 틀 조각을 문자열로 떠 두는 표면.
  조판기가 `element` 를 직접 만지지 않게 한다.
- `template.capture_page_headers()` 추가. **`clear_body()` 앞에서** 머리말 run 을 떠
  구역별로 돌려준다. `open_template()` 이 `roles["_page_header"]` 로 실어 준다.
- `mock_to_hwpx.num_prefix_xml()` 추가. 자릿수에 따라 탭 1개(636) 또는 2개(132·671).
- `mock_to_hwpx.page_starts()` 추가 — 편집기 `buildPages()` 와 같은 규칙(**단 두 개가
  한 쪽**). `build()` 가 그 자리에 `pageBreak` 를 주고, 구역마다 **첫 쪽나눔 문단에만**
  머리말을 도로 넣는다(실물과 같게 — 여러 번 넣으면 쪽마다 겹쳐 찍힌다).
- `set_masthead_elective()` 가 **모든** `수학 영역(…)` 을 고치도록 하고, 반환값 의미를
  '고쳤는가' 에서 **'이제 맞는가'** 로 바꿨다(고른 과목이 틀과 같으면 고칠 것이 없는데
  그걸 실패로 보고해 헛경고가 붙었다). 머리말은 반복문에서야 문서에 들어가므로
  `build()` 가 **문항을 다 쓴 뒤 한 번 더** 부른다.

### 고치다 만든 회귀 둘 (되돌리지 말 것)

- ⚠️ **쪽나눔과 단나눔을 같은 문단에 함께 주면 안 된다.** 쪽 시작은 단 시작이기도 해서
  처음엔 둘 다 붙었다(5건). 한글이 **둘 다 수행해** 새 쪽으로 넘어간 뒤 다시 단을
  넘기므로 새 쪽의 왼쪽 단이 통째로 빈다. 쪽나눔이면 단나눔은 주지 않는다.
- ⚠️ `test_sections.py` 의 `section_text()` 가 `<hp:tab/>` 을 지우고 머리말 글자까지
  본문에 이어 붙여, **27번이 사라진 것처럼** 보였다(`…통계)3` + `27.` = `…)327.` 이
  되어 번호 정규식의 앞막음에 걸렸다). 탭은 공백으로 펴고 머리말·꼬리말은 본문에서
  뺀다. 문서는 멀쩡했고 검사만 틀렸다.

## 검증

- `experiments/hwp-export/test_page_layout.py` 신설 — `scripts/check-hwpx.mjs` 에 걸었다.
  번호 탭 개수·너비, 쪽나눔 개수가 편집기 규칙과 같은지, 쪽나눔·단나눔 겹침 없음,
  머리말 존재·한 번만·선택과목 반영을 본다.
- **일부러 되돌려 빨간불을 확인했다**(그 확인도 검사 안에 넣었다):
  번호를 공백으로 → 잡힘 · 쪽나눔을 없앰 → 잡힘, 그리고 그때 머리말도 함께 사라짐.
- `npm run check:fast` 통과 (HWPX 10건 전부 실행).
- `npm run test:hwpx-opens` — 고친 시험지와 범용 문서 **둘 다 실물 한글에서 열린다.**
