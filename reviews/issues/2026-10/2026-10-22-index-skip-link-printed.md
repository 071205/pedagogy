## 요약과 영향

시험지 PDF 첫 쪽 하단에 화면 탐색용 `본문으로 건너뛰기` 링크가 출력된다. 문항과 지문 범위는 정상이나 시험지에 불필요한 UI 문구가 들어간다. REV-108의 명시 소속/버전 게이트와 별개다.

## 재현 절차

1. 운영 Pages `625e19c`의 문제집 편집기에서 자체 작성 4문항 테스트 권을 연다. 첫 3문항은 공통지문, 4번은 독립이며 옛 묶음을 확정한 상태다.
2. 인쇄 → 정답 제외 → Chrome PDF로 저장(여백 없음)을 실행한다. 키보드 건너뛰기 링크를 의도적으로 포커스하지 않았다.
3. 저장 PDF를 렌더하면 첫 쪽 왼쪽 아래에 `본문으로 건너뛰기`가 보인다. PDF 텍스트 추출에도 같은 문구가 남는다.

## 기대 결과 / 실제 결과

- 기대: 인쇄에는 시험지 내용만 나오며 화면 탐색 링크는 제외된다. 화면의 키보드 접근 경로는 유지한다.
- 실제: A4 2쪽 PDF 중 첫 쪽 하단에 회색 탐색 링크가 출력된다.

## 근거

- 배포 `index.html`은 검증 소스와 바이트 일치한다. `.skip-link`는 본문 밖의 fixed 요소이며 화면에서는 transform으로 숨긴다. `@media print`의 숨김 목록에는 `.skip-link`가 없다(`index.html`의 `.skip-link`, `@media print`, `a[href="#appMain"]`). 원인 전체를 CSS 누락만으로 단정하지 않지만 실제 출력 누락 방어가 필요하다.
- 증거 사본 `/private/tmp/rev108-operational-2026-10-22/rev108-printed.pdf`와 `print-page-1.png`, `print-extracted.txt`. 임시 자료 소실 시 위 절차로 재생성한다. 이 PDF는 자체 작성 검증 자료이며 계정 식별자/사용자 기존 문제를 포함하지 않는다.
- 같은 출력에서 `[01~03]`, 공통지문/4문항·독립 4번은 정상이다.

## 제안

인쇄 미디어에서 화면 탐색 링크를 제외하고, 실제 print 미디어/생성 PDF의 문구 부재를 검사한다. 화면 첫 Tab → Enter의 본문 이동도 유지되는지 확인한다. 숨김 방어를 제거한 RED가 새 검사를 실패시키도록 검증한다.
