# 편집기 입력과 아이콘 조작의 접근 가능한 이름이 빠졌다

- ID: `REV-2026-068`
- 날짜: `2026-09-09`
- 보고자: `Codex`
- 상태: `resolved`

- 관련 인계: `HANDOFF-2026-088`

## 요약과 영향

정적 메타 입력과 동적 블록 입력 일부가 placeholder 또는 연결되지 않은 `div.label`에만 기대고, 선지 삭제·순서 손잡이는 이름이 비어 화면낭독기에서 목적을 알 수 없었다. 문항 열기와 추가도 클릭 전용 `div`였다.

## 재현 절차

1. 문제집을 열고 문항 정보와 문제 본문·선지 블록을 렌더한다.
2. 가시적 `input/select/textarea/button`의 접근 가능한 이름과 문항 목록의 태그를 조사한다.

## 기대 결과 / 실제 결과

- 기대: 모든 조작에 문맥을 포함한 이름이 있고 문항 열기·추가는 키보드로 실행된다.
- 실제: 상단 문구·본문 textarea·선지 삭제 버튼 등이 이름 없이 노출됐다.

## 근거

수정 전 브라우저 점검에서 가시적 무명 컨트롤 7개가 재현됐고 독립 코드 검토가 전체 블록 유형에서 같은 패턴을 확인했다.

## 처리 기록
