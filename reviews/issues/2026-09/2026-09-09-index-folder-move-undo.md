## 요약과 영향

폴더 이동이 350ms debounce 경계를 확정하지 않았고 A단계의 folderBySetId는 히스토리 밖이었다. 즉시 Undo는 A/B 모두 작동하지 않고, A는 기다려도 소속을 되돌릴 수 없다.

## 재현 절차

문제집을 수학에서 영어로 이동한 즉시 Undo한다. 기대는 수학 복원이나 실제는 영어 소속 유지다. 새 이동 UI를 붙인 뒤에도 동일 검사가 A/B 모두 실패했다.

## 기대 결과 / 실제 결과

기대는 조작 대상과 화면·저장 상태가 일치하는 것이다. 실제 불일치는 위 절차 및 `scripts/check-library-ui.mjs`에서 재현했다.

## 근거

기준 커밋 `96e9d83`의 `index.html`과 실제 Chromium 클릭 검사. UI 검사는 외부 통신을 차단한 별도 브라우저 저장소에서 수행한다.

## 처리 기록

- 2026-09-09 — Codex: 이동을 historyStep으로 감싸 즉시 한 단계로 기록한다. A단계에 한해 폴더 소속 지도를 snapshot에 포함하고 복원 후 writeLibMeta한다. 폴더 목록과 tombstone은 히스토리에 넣지 않아 Undo로 삭제 폴더를 살리지 않는다. Undo/Redo와 새로고침, tombstone 우선 판정을 검사한다.
- 검증: `npm run test:library-ui`. 수정 전 실패와 수정 후 통과를 확인하며 기존 라이브러리 계약·브라우저 회귀도 함께 실행한다.
