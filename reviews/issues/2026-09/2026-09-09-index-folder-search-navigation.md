# 검색 중 폴더 클릭이 무효처럼 보이고 결과의 소속도 빠짐

## 요약과 영향

전체 검색은 폴더 필터보다 우선하지만 칩 클릭은 검색어를 유지했다. 결과 카드의 폴더명은 libFolderFilter가 비어 있을 때만 표시해 다른 폴더의 검색 결과도 소속을 숨겼다.

## 재현 절차

수학 폴더에서 영어 폴더의 문제집 이름을 검색한다. 결과에 영어 폴더명이 없다. 수학 칩을 눌러도 검색 결과가 그대로다.

## 기대 결과 / 실제 결과

기대는 조작 대상과 화면·저장 상태가 일치하는 것이다. 실제 불일치는 위 절차 및 `scripts/check-library-ui.mjs`에서 재현했다.

## 근거

기준 커밋 `96e9d83`의 `index.html`과 실제 Chromium 클릭 검사. UI 검사는 외부 통신을 차단한 별도 브라우저 저장소에서 수행한다.

## 처리 기록

- 2026-09-09 — Codex: 폴더 클릭은 검색을 지우고 해당 폴더로 이동한다. 검색 중에는 어떤 폴더 칩도 선택 표시하지 않으며 결과 카드의 실제 소속을 표시한다. 선택한 폴더를 다시 클릭해도 전체로 튀지 않는다.
- 검증: `npm run test:library-ui`. 수정 전 실패와 수정 후 통과를 확인하며 기존 라이브러리 계약·브라우저 회귀도 함께 실행한다.
