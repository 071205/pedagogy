# 핵심 단추 검사가 사라진 단추와 세로 화면 밖 단추를 통과시킨다

- ID: `REV-2026-025`
- 날짜: `2026-09-07`
- 보고자: `Codex`
- 상태: `resolved`
- 심각도: `P2`
- 영향 영역: `tests`
- 관련 인계: `HANDOFF-2026-053`

## 요약과 영향

교차 플랫폼 검사의 "핵심 단추가 화면 안" 판정은 없는 단추를 검사 대상에서 제외하고,
있는 단추도 가로 좌표만 확인한다(`scripts/check-cross-platform.mjs:114-123`). 따라서 핵심
단추가 DOM에서 사라지거나 화면 위·아래로 밀려 사용자가 누를 수 없어도 검사 결과는
초록불이다. 현재 자기검사는 단추를 왼쪽으로 옮기는 경우만 검증해 두 맹점을 잡지 못한다.

## 재현 절차

Chromium 375×812 화면에서 현재 검사와 같은 판정식을 실행했다.

1. `printBtn`을 제거: `{id:"printBtn", missing:true}`였지만 전체 판정은 `passes:true`.
2. `saveBtn`을 `top:-500px`로 이동: 실제 `top`은 -500이지만 `inView:true`, 전체 판정도
   `passes:true`.

## 기대 결과 / 실제 결과

- 기대: 필수 단추가 없거나 가로·세로 화면 밖이면 실패한다.
- 실제: 누락은 무시하고 `left`·`right`만 검사해 두 경우 모두 통과한다.

## 수정·검증 기준

- `missing`이 하나라도 있으면 실패해야 한다.
- 화면 안 판정에 양의 너비·높이와 `top`·`bottom` 범위를 함께 포함해야 한다.
- 단추 제거와 세로 이탈을 각각 자기검사로 추가하고, 해당 판정을 일부러 제거했을 때 각
  검사가 빨간불이 되는지 확인한다.

## 처리 기록

- 원인: **내가 판정에서 스스로 눈을 가렸다.** `off = btns.filter(b => !b.missing && !b.inView)`
  의 `!b.missing` 은 '없는 단추는 시끄러우니 빼자' 는 생각이었는데, 그 결과
  **단추가 사라져도 초록불**이 됐다. `inView` 도 `left`/`right` 만 봐서 세로 이탈을 놓쳤다.
- 수정: `missing` 이면 `inView:false` 로 두어 그대로 실패시킨다. `inView` 에
  **`height>0` 과 `top`/`bottom` 범위**를 더했다.
- 검증: 자기검사에 **두 맹점을 각각** 더했다 — `top:-500px` 로 밀기, 단추 지우기.
  둘 다 빨간불을 확인했고, 기존 가로 이탈 검사도 그대로 빨간불이다.
