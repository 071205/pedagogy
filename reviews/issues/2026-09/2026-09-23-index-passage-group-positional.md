# 지문 묶음이 위치로만 정해져, 가운데 문항을 지우면 무관한 문항이 묶음에 흡수된다

- 상태: `open`

## 요약과 영향

공통지문 묶음은 **지문을 가진 첫 문항의 `groupSpan` 과 배열 위치**로만 정해진다
(`computeNums()` 가 `res[i+span-1]` 을 끝으로 삼는다). 묶음 구성원에 대한 역참조가 없어서,
가운데 문항을 지우면 `groupSpan` 이 그대로 남아 **뒤의 무관한 문항이 그 지문 묶음에
흡수된다.** 인쇄본에는 `[01~03]` 같은 범위 라벨이 찍히므로 **지문과 상관없는 문항이 그
지문에 딸린 것처럼 출력된다.**

⚠️ **오류도 경고도 나지 않는다.** 데이터는 유실되지 않지만 **출력물이 조용히 틀린다** —
이 저장소가 반복해 겪은 실패 방식 1번(검사는 초록불인데 결과물이 틀림)과 같은 모양이다.

문항 삭제 핸들러(`index.html:6244`)는 **바로 옆에서 인쇄 짝(`paired`)은 보정한다**
(`if(fi>0 && arr[fi-1].paired) setPair(arr[fi-1],false);`). 같은 자리에서 `groupSpan` 만
빠져 있어, 의도된 결정이 아니라 **누락**으로 보인다(가설).

U0 계약(`docs/PRODUCT-UX-U0-CONTRACT.md` §3)이 설계 중인 **AI 구성안의 문항 이동·제외**는
이 동작을 그대로 상속한다. 계약은 '묶음 단위 이동' 과 '분리 시 지문 동반 검증' 만 적고 있어
**제외·재배열로 생기는 목적지 쪽 흡수**는 아직 계약에 없다.

## 재현 절차

1. 문제집에 문항 넷을 둔다 — `P1`(지문 블록 보유 · `groupSpan:3`) · `P2` · `P3` · `Q4`.
   (`P1` 의 지문이 `P1~P3` 세 문항의 공통지문이고 `Q4` 는 무관한 문항이다)
2. 문항 목록에서 **`P2` 를 삭제**한다.
3. 인쇄/미리보기의 지문 머리 라벨을 본다.

## 기대 결과 / 실제 결과

- 기대: 묶음이 `P1~P3` 두 문항으로 줄어 `[01~02]` 가 되거나, 최소한 사용자에게
  묶음이 깨졌음을 알린다.
- 실제: `groupSpan` 이 3으로 남아 범위가 **`[01~03]`** 으로 찍히고 **`Q4` 가 그 지문
  묶음에 들어간 것처럼** 출력된다.

## 근거

`pedagogy-print.js:96` — 끝 문항을 **위치로만** 고른다. 경계 밖만 자르고 신원은 안 본다.

```js
const span=groupSpanOf(r.q);
if(span>1){
  const last=res[Math.min(i+span-1, res.length-1)];
  if(last && last!==r) r.range=r.num+"~"+last.num;
}
```

세 모듈을 Node 로 그대로 불러 `computeNums()` 를 돌린 결과(순수 함수 재현):

| 상황 | 결과 |
|---|---|
| 원래 `P1(span3) P2 P3 Q4 Q5` | `P1:01 [01~03]` — 맞다 |
| **`P2` 제외** → `P1 P3 Q4 Q5` | `P1:01 **[01~03]**` — `Q4` 흡수 |
| **`P1` 만 다른 권으로** → `X1 P1 Y2 Y3` | `P1:02 **[02~04]**` — 무관한 `Y2·Y3` 흡수 |
| **`P2·P3` 만 다른 권으로** → `Z1 P2 P3` | 범위 없음 — **지문이 조용히 사라짐** |

`index.html:6244` 의 삭제 경로에 `groupSpan` 보정이 없다(`groupSpan` 쓰기 지점은
`index.html:6472` 의 선택 UI 하나뿐이다).

⚠️ 위 셋 중 **첫째 줄(제외)만 현재 UI 로 바로 재현된다.** 둘째·셋째는 문항을 다른 권으로
옮기는 경로가 지금 제품에 없어 **순수 함수 수준에서만 확인**했다 — U0 이 그 경로를 만들면
그대로 발생한다.

## 제안 (선택)

- 삭제·재배열에서 `paired` 를 보정하는 그 자리에서 `groupSpan` 도 **실제 남은 연속 구성원
  수로 다시 계산**한다. 구현자는 '묶음을 줄인다' 와 '사용자에게 알리고 그대로 둔다' 중
  어느 쪽이 맞는지 먼저 정할 것 — 조용히 줄이는 것도 사용자의 의도를 덮을 수 있다.
- U0 §3 에 **목적지 쪽 흡수**를 계약으로 추가한다. 채택 시점에 `groupSpan` 을 실제 배치된
  연속 구성원으로 다시 쓰고, 지문 없는 뒤 문항만 옮기는 선택은 막거나 지문을 동반시킨다.
- 회귀는 **범위 라벨 문자열**로 본다(`[01~03]`). 블록 단위 검사는 전부 초록불이다 —
  `REV-2026-019`·`-020` 과 같은 '관계를 봐야 잡히는' 부류다.
