# 인쇄 넘침 보정이 표 자체의 가로 넘침을 놓친다

- ID: `REV-2026-078`
- 날짜: `2026-09-10`
- 보고자: `Codex`
- 상태: `resolved`
- 심각도: `P2`
- 영향 영역: `index | tests`
- 관련 인계: `HANDOFF-2026-108 | HANDOFF-2026-109 | HANDOFF-2026-110`

## 요약과 영향

`fitPrintDoc()`은 여러 열 선지와 `.katex-display`는 가로 보정하지만 `.ktbl` 자체는 보지
않는다. 합친 칸에 줄바꿈할 수 없는 긴 내용이 들어간 표를 인쇄하면 단 오른쪽으로 넘친 채
잘리지만, 함수는 보정하지 않고 성공으로 보고한다. 표 칸 그림과 합치기 지원 뒤에도 정상 폭
표본만 있어 회귀 검사가 이 실패를 잡지 못한다.

## 재현 절차

1. 로컬 `index.html`의 실제 인쇄 DOM에 `tableHTML()`로 3열 탐구 표를 넣는다.
2. 첫 칸을 `colspan=3`으로 합치고 그림과 줄바꿈할 수 없는 긴 값을 같은 칸에 둔다.
3. 표와 `.slot`의 오른쪽 경계를 잰 뒤 `fitPrintDoc()`을 호출하고 다시 잰다.

## 기대 결과 / 실제 결과

- 기대: 표가 단 폭 안으로 축소되거나 보정 실패 목록에 포함돼 사용자에게 경고한다.
- 실제: 표 오른쪽이 단 오른쪽보다 `1897.53px` 밖인데도 호출 전후 경계가 같고,
  표의 `transform`은 빈 값이며 반환된 넘침 건수도 `0`이다.

## 근거

- 실측 전: `tableRight=-7718.86`, `slotRight=-9616.39`; 실측 후도 동일.
- `fitPrintDoc()`의 2단계 선택자는 `.pq .content .katex-display`뿐이고 `.ktbl`은 없다.
- 정상 폭 `08-inquiry-table`은 0.000%로 통과해 의도적인 가로 초과를 검출하지 않는다.

## 제안 (선택)

현재 읽기/쓰기 분리 규칙을 유지하면서 `.pq .ktbl`도 폭 측정 대상으로 모으고, 예약 높이까지
맞는 표 전용 축소 계약과 고장 주입 회귀를 추가한다.

## 처리 기록

- `2026-09-10` — `Codex`: Chromium에서 합친 칸·그림·긴 내용을 가진 실제 인쇄 DOM으로
  호출 전후를 측정해 등록했다. 제품 코드는 수정하지 않았다.

- `2026-09-10` — `Claude`: 해결. **원인**은 보고 그대로다 — `fitPrintDoc()` 의 2단계
  선택자가 `.pq .content .katex-display` 뿐이라 표를 아예 재지 않았다.
  ⚠️ **표는 `width:100%` 여도 넘친다** — min-content 아래로 못 줄기 때문이다. 그래서
  '폭을 100%로 묶어 뒀으니 넘칠 리 없다' 는 짐작이 틀렸다.
  **수정**: `pedagogy-print.js` 에 `shrinkWideTablesAll()` 을 더하고 `fitPrintDoc` 의
  (2-b) 단계에서 `.pq .ktbl` 을 모아 넘기는 것만 줄인다. 기존 **읽기 → 쓰기 분리**를
  그대로 지켰다(해제 → 일괄 측정 → 일괄 적용).
  ⚠️ **`transform` 은 자리를 안 줄인다.** 그대로 두면 남는 높이만큼 세로 넘침 판정
  (3단계)이 과대평가돼 멀쩡한 쪽에 '안 담김' 경고가 뜬다. 아래 여백에서 그만큼 뺐고,
  여백 기준값은 **CSS 에서 읽는다**(2mm 를 코드에 박으면 CSS 를 고칠 때 조용히 어긋난다).
  ⚠️ **(2-b) 는 3단계보다 먼저** 와야 한다 — 순서가 뒤바뀌면 줄이기 전 높이로 판정한다.
  **회귀**: `tests/regression-test.html` 이 `#printDoc` 에 넘치는 표를 직접 심고
  `.measuring` 으로 펼친 뒤 `fitPrintDoc()` 전후를 잰다. **넘침이 사라졌는지**와
  **유령 높이가 제거됐는지**를 함께 본다(사용자 데이터는 건드리지 않는다).
  고장 주입 둘 다 확인 — 보정 호출을 지우면 빨간불, **여백 보정만 지워도 빨간불**.
  검증: `npm run check:fast` 통과(브라우저 회귀 **158/158**) ·
  `npm run test:visual` 9종 통과(정상 폭 표는 그대로라 픽셀 0.000%).
