## 요약과 영향

saveSets는 currentSetId만 touch했다. 라이브러리에서 다른 카드의 이름을 바꾸면 그 카드의 수정 시각은 갱신되지 않고 마지막으로 연 문제집 시각이 바뀌었다.

## 재현 절차

가 문제집을 열었다가 라이브러리로 돌아와 최근 수정순을 선택한다. 나 카드 이름을 다로 바꾼다. 다가 최근 수정 위치로 이동하지 않고 가의 시각이 갱신된다.

## 기대 결과 / 실제 결과

기대는 조작 대상과 화면·저장 상태가 일치하는 것이다. 실제 불일치는 위 절차 및 `scripts/check-library-ui.mjs`에서 재현했다.

## 근거

기준 커밋 `96e9d83`의 `index.html`과 실제 Chromium 클릭 검사. UI 검사는 외부 통신을 차단한 별도 브라우저 저장소에서 수행한다.

## 처리 기록

- 2026-09-09 — Codex: saveSets의 변경 대상 ID를 선택 인자로 받도록 했다. 이름 변경·복제·신규 생성은 실제 ID를 전달하며, 편집기 기존 호출은 currentSetId 기본값을 유지한다. 최근 수정순 버튼에 현재 기준을 표시하고 Escape로 정렬 메뉴를 닫는다.
- 검증: `npm run test:library-ui`. 수정 전 실패와 수정 후 통과를 확인하며 기존 라이브러리 계약·브라우저 회귀도 함께 실행한다.
