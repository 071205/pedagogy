# 설정이 출처 화면을 잊고 모의고사 편집기에는 진입점이 없다

- 상태: `resolved`

## 요약과 영향

`showSettings()`가 마지막 문제집 기억을 즉시 지우고 `settingsBack`이 항상 기본 문제집
라이브러리만 열었다. 따라서 문제집 편집기나 모의고사 라이브러리에서 설정을 열면 보던 자리로
돌아가지 못했다. 모의고사 편집기에서는 설정 진입 버튼도 모두 숨겨져 있었다.

## 재현 절차

1. 문제집 `a`를 열고 설정 버튼, 뒤로 버튼을 차례로 누른다.
2. 모의고사 라이브러리에서 설정을 열고 뒤로 간다.
3. 모의고사 편집기를 열어 보이는 설정 버튼을 센다.

## 기대 결과 / 실제 결과

- 기대: 설정은 편집을 끝내지 않고 문제집/모의고사 편집기 또는 원래 라이브러리 갈래로
  돌아간다. 모의고사 편집기에서도 설정을 열 수 있다.
- 실제(수정 전): 문제집 `readLastSet()`은 `a`에서 `null`이 되고 뒤로 가면 문제집
  라이브러리다. 모의고사 라이브러리도 문제집 갈래로 바뀌며 모의고사 편집기의 설정 진입점은
  계산된 폭 0인 숨은 버튼뿐이다.

## 처리 기록

  뒤로 가기 문구와 복귀 대상을 맞췄다. 설정 진입 때 `rememberSet(null)`을 호출하지 않으며,

  왕복 뒤 유지되고, 모의고사 편집기 설정 버튼이 보이며 같은 모의고사로 복귀함을 확인했다.
  세 경로를 `check-library-ui.mjs`에 회귀로 추가하고 정적 한컴 접근 계약에도 모의고사 설정
  입구를 포함했다.
