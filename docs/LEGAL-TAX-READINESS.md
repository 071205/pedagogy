# L1·L2 법무·세무 준비 계약

2026-10-08 · [통합 레일 R9](DEV-TOKEN-ROADMAP.md)의 L1·L2 완료 조건을 구체화한다.
실행 순서와 상태는 통합 레일만 관리한다. 가격·사업자 형태·공급자를 여기서 확정하지 않는다.
P1은 초대 유료 베타, P2는 공개 판매다. P1도 등록·고지·동의·환불·개인정보 의무를 줄이지 않는다.

## 1. 담당과 증거

Claude 초안 → Codex 독립 대조 → 해리의 실제 운영 사실 확정·등록·게시를 기본 경로로 한다.
상시 유료 전문가 계약은 공통 선행 조건이 아니다. 모델 간 합의나 표준 문구만으로 적법성을 증명하지 않는다.
판단에 필요한 사실이 없으면 빈칸과 영향을 남기고, 법 해석이 남으면 관할 공공 창구에 좁게 질문한다.
해당 출시 행위의 적법성에 직접 영향을 주는 미결 항목은 해결 근거가 생길 때까지 그 행위를 열지 않는다.

각 검토 항목에는 `문서/조항 · 실제 운영 사실 · 법령 조문/공식 URL · 시행일/확인일 · 적용 판단 ·
코드/UI 근거 · 미결 질문 · 담당 · 확인 결과`를 남긴다. 상담 답변은 질문의 사실관계·일자·기관을 함께
기록한다. 전화 자문을 법적 보증으로 쓰거나 개인정보·사업자 서류 원문을 공개 저장소에 올리지 않는다.
기존 HANDOFF에 최종 결과와 관련 파일만 연결한다. 모델 호출은 AGENTS의 왕복 예산을 따른다.

## 2. L1 — 사업자·세무·통신판매

| 작업 | 작성물 | 완료 근거와 연결 |
| --- | --- | --- |
| 운영 사실 정리 | 운영자 형태/소재지·기존 사업장·판매 대상·서비스 내용·예상 매출·결제 수단·증빙 요구표 | 해리 확인. 교육 도구라는 이름만으로 교육용역 면세나 업종을 확정하지 않음 |
| D9 과세 판단 | 일반/간이 적용·배제 조건·신규 사업자 기간·세금계산서/현금영수증/카드전표 구분 | 현행 조문과 실제 사실 대조. 필요한 세무 질문만 126/관할 세무서/마을세무사로 |
| 등록·신고 | 사업자등록 결과, 통신판매 신고 또는 면제 적용 근거·재확인 조건 | 해리가 실행. 통신판매 문의는 사업장 관할 지자체. 신고 면제가 다른 소비자 의무의 면제는 아님 |
| 증빙·장부 운영 | PG 정산·수수료·매출·환불·증빙 발행의 주체/절차·신고 일정 | L3 계약과 F2/F3c 장부·대사에 연결. PG 영수증을 세금계산서와 혼동하지 않음 |
| 변경 관리 | 매출/판매 방식/과세 유형/사업장 변경 때 다시 볼 항목 | 면제 근거·등록 정보·표시·가격 세금 계산을 재대조할 담당과 시점 기록 |

**L1 완료**: 등록/면제 적용과 증빙 운영을 뒷받침하는 실제 확인 기록이 있고, L2 사업자 표시와
F3/F4 결제·환불 증빙이 같은 사업자를 가리킨다. 후보 업종이나 추천 과세 유형만으로 완료하지 않는다.
판매 가격의 세금 계산은 D9 확정 뒤 적용한다. 일반과세의 VAT 예시를 간이과세 납부세액으로 쓰지 않는다.

## 3. L2 — 문서 작성부터 동의·운영 검증까지

| 작업 | 작성물 | 완료 근거와 연결 |
| --- | --- | --- |
| 데이터 흐름 | 로그인·원문/응답·편집 자료·AI 전송·결제·지원·로그별 수집 항목/목적/처리자/위치/보존/삭제 표. **기계가 읽는 `docs/legal/processing.json` 으로 쓰고 코드의 외부 호스트·Rules 필드 → 명세 → 약관 3방향 검사**([융합 설계 §②](EXTERNAL-IDEAS-FUSION-DESIGN.md)) | D8/D12/D13·R7 실제 계약/콘솔과 대조. 위탁·제3자 제공·국외 이전을 각각 판단 |
| 문서 초안 | 이용약관·처리방침·사업자 표시·상품/환불 고지·정기결제 전환 안내·권리 신고 절차 | 공정위/과기정통부 표준 문서와 개인정보위 최신 지침 출발. 서비스에 맞게 바꾼 이유와 조문 근거 기록 |
| 최종화 | 조항별 근거표·미결 질문/답변·확정 문서 원문/버전 | D7/D8/D10/D11/D12/D13·L1/L3 사실 반영. L2 초안은 지금 가능하며 PG 선택을 먼저 강제하지 않음 |
| 게시·동의 | R7 호스트의 문서, 결제 직전 고지, 재동의·철회·해지 경로, 과거 버전 보관 | F3a 서버 증적·F3b UI 연결. 문서/설정/동의 버전과 실제 요금·상태 일치 |
| 운영 확인 | 환불/권리 신고/지원 접수·탈퇴/법정 보존·공급자 실패 시 처리 기록 | F4·R8 결제 확장에서 실제 경로 확인. P1 수동 이메일/PG 콘솔도 담당·처리·대사 증거 필요 |

구체적으로 다음 경계를 검토한다.

- 무료→유료·가격 인상 동의, 적용 시점, 갱신·해지 조건, 사용량/잔여 권리 표시를 결제 설계 §4-2와 맞춘다.
  사용 시작 체크박스만으로 모든 청약철회를 배제하지 않으며, 가분적 콘텐츠 미사용분·하자/계약 불일치를 별도 판단한다.
- 서버 동의 기록은 문서 버전/원문 또는 해시·서버 시각·목적별 선택·철회/변경 이력을 보존한다.
  현재 사용자가 덮어쓰는 `prefs/consent`를 불변 증적으로 취급하지 않는다. 선택 AI 전송을 로그인 동의와 묶지 않는다.
- 계정 삭제와 법정 거래 기록 보존을 구분한다. 종류별 근거·항목·기산점·기간·접근자·기간 종료 후 파기를 정한다.
  거래 장부 때문에 원문/응답을 같은 기간 보관하거나 삭제 원문을 복원하지 않는다. 백업 파기도 따로 정한다.
- 권리 신고는 본인/권리 확인·접수·조사·가능한 서비스 조치·결과 통지·이의 절차를 정한다.
  서버에 없는 기기 원문까지 원격 삭제하거나 모든 신고를 즉시 비공개 처리한다고 약속하지 않는다.
- 미성년자 정책과 AI 공급자 적격성(D12), 국외 이전 근거·안내·거부 시 영향, 책임자/문의 연락처를 실제 운영에 맞춘다.
  공급자 이름만 적고 처리 국가·수탁 조건·보존 기간이 확인됐다고 주장하지 않는다.
- 현재 `legal.html`의 전문가 검토 안내·미확정 노란 항목·14세 기준은 L2 게시 때 확정 정책에 맞게 갱신한다.
  문서에 적힌 기능이 아직 없으면 F3/F4 수용 조건으로 남기며 구현 완료로 표시하지 않는다.

**L2 완료**: 근거표와 실제 계약·운영 사실이 맞고, 필수 미결 항목이 해소됐으며, 게시된 문서와 제품 동작을
F4/R8에서 확인한다. `check:static`의 제목 존재나 버전 일치만으로 법률 검토를 통과했다고 하지 않는다.
새 동의/해지/환불/파기 회귀 검사는 고장 주입으로 red를 확인하고 CI에 연결한다. 런타임 변경 때 CSP도 확인한다.
P1 자동 알림을 유예하더라도 법정 안내를 유예하지 않는다. 수동 전달·처리 이력으로 필요한 안내를 확인한다.
P2 전에 대상·상품·공급자·국가·데이터·지원/알림 변화와 P1 문의/분쟁을 재대조하고 변경분을 다시 검토한다.

## 4. 남는 질문의 관할

| 질문 | 창구 | 조건 |
| --- | --- | --- |
| 업종·VAT·증빙 발행 | 국세상담 126/관할 세무서·지자체 마을세무사 | 126은 통화료 유료. 마을세무사는 실제 대상/지역 확인 |
| 통신판매 신고/면제의 실제 적용 | 사업장 관할 시·군·구 | 거래 횟수·과세 유형·판매 형태를 제시 |
| 국외 이전·처리방침 해석 | 개인정보위 법령해석/공식 지침·포털 | 실제 데이터 흐름과 조항을 붙여 질문 |
| 업로드 권리·권리자 신고 | 한국저작권위원회 상담 | 권리 관계·이용 방식·조치 가능 범위 제시 |
| 지원받는 전체 약관 검토 | 현행 K-Startup 등의 지원 공고 | 2025 공고의 지원액/대상을 2026 자격으로 확정하지 않음. 선정이 전체 레일의 선행은 아님 |

  [법제처 등록·신고 안내](https://www.easylaw.go.kr/CSP/EasyLawInfoR.laf?csmSeq=2985&easySeq=3988): 면제 기준과 관할 지자체.
  이번 고시 본문은 웹 추출로 확인되지 않아 법제처 안내로 기준을 교차 확인했다. L1 최종 적용 때 고시 원문도 보존한다.
- [국세청](https://www.nts.go.kr/): 126 상담 범위와 유료 전화 표기.
- [개인정보위 작성지침 2026.4](https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS217&mCode=D010030000&nttId=12018):
  2026-04-23 공개된 현행 안내서. 첨부 지침 전문 대조는 L2 작성 시 수행한다.
- [개인정보 보호법 제30조](https://www.law.go.kr/법령/개인정보보호법/제30조),
  [시행령 제31조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1033215161):
  2026-09-11 시행 조문으로 파기·위탁·책임자·쿠키·항목·국외 이전·안전조치 기재 근거 대조.
- [공정위 표준약관 공시](https://www.ftc.go.kr/www/selectBbsNttList.do?bordCd=201&key=202&pageIndex=1&pageUnit=10&searchCnd=all):
  개별 표준약관의 현행 원문/개정일 확보는 L2 작성 때 수행한다. 전자상거래 표준약관을 SaaS에 그대로 적용하지 않는다.

전자상거래법의 결제 전환·청약철회 근거는 [결제 기반 설계 §4-2](BILLING-FOUNDATION-DESIGN.md)에 연결한다.
출시 시점에는 확인일 이후 개정과 실제 적용일을 다시 대조한다.
