# 시험지 미리보기·출력 점검 동작

진행 상태와 모델·운영 게이트는 [통합 레일](DEV-TOKEN-ROADMAP.md)에 둔다.
사용자 우선순위는 시험지 미리보기·출력 완성도다.

## 지면을 확인하는 동안

- 쪽 선택·이전/다음·축소판·확대는 종이 viewport 안에서만 스크롤한다. 바깥 패널을 움직여
  도구/글꼴·그림·잘림 경고를 가리지 않는다. 100%에서 문항이 viewport보다 크면 번호와 시작부터 보여준다.
- 좁은 화면은 실제 남은 높이로 지면을 스크롤한다. 문항 설정은 기본 접힘이고, 문항/경고를
  명시적으로 고르면 설정을 펼친다. 선택 문항과 확인 필요 수는 접힌 제목에서도 보인다.
- 펼친 설정은 지면을 밀지 않는 패널이고 가용 높이 안에서 자체 스크롤한다. Escape로 닫으면
  제목으로 초점이 돌아간다. 초점이 패널 밖으로 나가면 닫힌다. 넓은 화면에서는 항상 펼친다.
- 원본 대조는 좁은 화면에서 body 높이의 절반 이내로 나눠 쓰며 원본 자체도 스크롤할 수 있다.
  여러 쪽 문서도 원본 영역을 누르지 않도록 실제 남는 높이를 분배한다.
  원본과 설정을 함께 열어도 양쪽 영역과 원본 연결 도구를 사용할 수 있다.

## 출력 전 확인

`확인할 문항`에서 잘림·축소·그림 실패 사유를 확인하고 필요하면 한 쪽 배치로 바꾼다.
한 쪽으로도 넘치는 문항은 내용을 나눈다. 배치 변경은 Undo 한 번으로 복구하며 경고도 다시 계산한다.
지면과 출력은 기존 buildPrintDoc/fitPrintDoc 경로를 공유한다. 화면용 스크롤·설정·원본 패널은
인쇄에서 제외한다. 실제 OS 인쇄/한글·실기기 검증 상태는 통합 레일의 R8에 따른다.
