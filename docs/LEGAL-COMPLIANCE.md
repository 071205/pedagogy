# 법정 기재사항 대조표

⚠️ **이 문서는 법률 자문이 아니다.** 법령이 요구하는 항목이 문서에 **있는지**를 대조한
체크리스트이고, 그 표현이 개별 분쟁에서 충분한지는 판단하지 않는다. 실제 요금을 받기
시작하면 전문가 검토를 한 번은 받는 것이 맞다. 다만 **빠진 항목을 채우는 일**은 여기서
끝냈다 — 빠짐은 표현의 문제가 아니라 사실의 문제이기 때문이다.

## 3. 아직 사람이 해야 하는 것 (코드로 못 끝낸다)

1. **`legal.html` 의 노란 항목** — 상호·대표자·주소·이메일·개인정보 보호책임자.
2. **유료화 시점에 법정 의무가 생기는 것** — 사업자등록번호·통신판매업 신고번호 표시
   (「전자상거래법」 제10조), 결제 화면의 청약철회·환불 기준 사전 고지.
   `legal.html#operator` 에 자리를 만들어 두었다.
3. **개인정보 보호책임자 지정** — 1인 사업자면 사업주 본인이 된다(법 제31조).
4. `service-config.js` 의 `legalVersion`·`supportEmail`.

## 4. 검사가 지키는 것

`check:static` 이 세 가지를 본다 — **사람이 지우거나 잊는 것을 막는 장치다.**

1. 방침에 위 표의 **법정 항목이 전부 있는가**(제목 문구로 확인).
2. `index.html` 의 `CONSENT_VERSION` 과 `legal.html` 의 문서 버전이 **같은가** —
   약관을 고치고 동의 버전을 안 올리면 "무엇에 동의했는지" 를 말할 수 없다.
3. 동의 창이 **필수 항목 네 개를 모두** 받고 있는가.
