# 글꼴 라이선스 — 견적 문의용 정리

PEDAGOGY 모의고사 편집기가 **정본(Typst) 출력**에 실제로 쓰는 글꼴 목록이다.
`mock-exam-editor.html` 의 `TYPST_FRAME` 안 `#let F-*` 정의에서 뽑았다.

브라우저 근사 미리보기용 글꼴(KoPub, Pretendard 등)은 이미 무료라 제외했다.

## 2. 이미 무료인 것 (문의 불필요)

- UnDinaru (은 디나루) — 은글꼴 프로젝트, 자유 이용
- New Computer Modern Math — OFL
- Libertinus Serif — OFL
- AppleMyungjo — macOS 번들 (배포 불가, 폴백으로만)
- KoPub 바탕 — 무료 상업 이용 가능
- Pretendard — SIL OFL

## 3. 문의할 때 핵심

**"웹폰트"가 아니라 "서버 사이드 렌더링 + PDF 임베딩"으로 물어볼 것.**
글꼴 파일이 서버 밖으로 나가지 않는 구조라 조건과 금액이 크게 다르다.

- ❌ 웹폰트 라이선스 = 글꼴 파일을 고객 브라우저로 전송 (비싸고 연 갱신)
- ✅ 서버 렌더링/임베딩 = 서버에서 조판해 **이미지·PDF 결과물만** 전송

## 4. 문의 메일 초안

> 제목: 웹 서비스 서버 사이드 렌더링용 글꼴 라이선스 견적 문의
>
> 안녕하세요.
> 수학 문제지(모의고사 형식) 제작 웹 서비스를 준비 중이며, 글꼴 라이선스 견적을 문의드립니다.
>
> **[사용 형태]**
> - 저희 서버에 글꼴을 설치하고, 서버에서 조판 엔진(Typst)으로 시험지를 조판합니다.
> - 사용자에게는 **조판 결과물(PNG 미리보기 이미지, PDF 파일)만** 전달됩니다.
> - **글꼴 파일 자체는 사용자에게 전송되지 않습니다** (웹폰트 방식 아님).
> - 최종 산출물은 사용자가 인쇄하거나 PDF로 배포하는 시험지입니다.
>
> **[대상 글꼴]**
> - (위 1번 표에서 해당 업체 것만 발췌해 기재)
>
> **[서비스 형태]**
> - 유료 구독형 웹 서비스 (예정)
> - 예상 이용자 규모: 초기 OO명 수준
>
> **[문의사항]**
> 1. 위 사용 형태에 필요한 라이선스 종류와 견적
> 2. PDF 임베딩 및 이미지 형태 배포가 허용되는지
> 3. 영구 라이선스 가능 여부 (연 갱신형만 있는지)
> 4. 이용자 수·매출 규모에 따른 구간이 있는지
>
> 감사합니다.

## 5. 참고

- 시험지의 **레이아웃·양식 자체는 저작권 대상이 아니다.** 글꼴 파일만 정리하면 된다.
- 다만 "평가원" 명칭·로고는 사용할 수 없다.
- 기출 문제를 콘텐츠로 제공하면 별도의 저작권 문제가 생긴다. 사용자가 자기 문제를
  입력하는 도구 포지션을 유지할 것.
- **최종 판단은 변호사 확인을 받을 것.** 이 문서는 견적 문의를 위한 정리일 뿐이다.
