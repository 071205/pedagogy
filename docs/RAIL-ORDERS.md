근거와 완료 조건은 [`DEV-TOKEN-ROADMAP.md`](DEV-TOKEN-ROADMAP.md) 가 정답표이고,
여기는 **누구에게 · 어떤 모델로 · 뭐라고 말할지**만 적는다.

⚠️ **한 메시지에 코덱스 호출 3회**가 예산이다. 다음 메시지에서 다시 3회다.
⚠️ **한 칸이 끝나면 다음 칸으로 간다.** 건너뛰면 검토자가 무엇을 봐야 할지 모르게 된다.

## 각 칸이 대체 무슨 일인가 — 쉬운 말로

### R4/B1~B7 = **"문제집이 안 날아가게 만든다"** 한 덩어리

지금 문제집은 로컬과 클라우드 양쪽에 있는데, **두 기기에서 같이 고치면 한쪽이 조용히
덮어씌워질 수 있다.** 그걸 일곱 조각으로 나눠 고치는 중이다.

| | 쉬운 말 | 상태 |
|---|---|---|
| **B1** | **너무 큰 문제집이 저장을 통째로 막던 것** — 큰 것만 빼고 나머지는 올린다 | 끝 |
| **B2** | **"내가 마지막으로 올린 게 이거였다" 를 기기마다 기록** — 안 그러면 뭐가 바뀌었는지 모른다 | 끝 |
| **B3** | **문제집마다 번호표(`revision`)를 붙인다.** 올릴 때 "내가 본 번호가 아직 맞나" 를 확인하고, 그사이 남이 고쳤으면 **덮지 않고 멈춘다.** ⚠️ 규칙을 한 번에 바꾸면 구버전이 거부당하므로 **3단계로 나눠 배포**한다 | **하는 중** |
| **B4** | **멈췄을 때 사용자에게 보여 줄 화면.** ⚠️ 자동 병합하지 않고 **어느 쪽도 버리지 않는다** — 내 것을 사본으로 따로 남기고 넷 중 고르게 한다 | 대기 |
| **B5** | **AI 호출 장부.** 지금은 "썼다" 기록과 실제 호출이 어긋날 수 있다. 계정 지우면 장부도 파기 | 대기 |
| **B6** | **여러 쪽 넣다 끊겼을 때 이어서 하기.** 중간 결과를 따로 두고 **기존 문제집은 안 건드린다** | 대기 |
| **B7** | **인터넷이 끊겨도 나중에 알아서 올라가게** (Service Worker) | 대기 |

### R4.5 = **"인쇄가 잘리지 않게"**

지금 선지가 칸을 넘으면 **말없이 잘려서 인쇄**된다. 보정 코드는 있는데 재는 대상이 틀려서
한 번도 안 걸렸다(`REV-2026-104`). 넘치면 5열 → 3열 → 2열 → 세로로 **한 단계씩 내린다.**

### R5 = **"지금까지 한 걸 한 번에 훑어본다"**

⚠️ **새로 검토하는 칸이 아니다.** B1~B7 과 R4.5 를 하면서 **묶음마다 이미 검토**를 받았고,
R5 는 그 결과를 모아 **빠진 것 · 고치다 생긴 영향 · 묶음끼리 안 맞는 곳**만 본다.
이미 통과한 건 다시 안 본다.

### R6 = **"검사와 부품 점검"**

우리 자동 검사(CI)가 실제로 다 돌았는지 대조하고, **비밀키가 실수로 들어간 적 없는지**,
쓰는 도구 버전이 흔들리지 않는지 고정한다. **코드를 바꾸는 칸이 아니다.**

### R7 = **"배포 환경 갈아타기"** ⚠️ 되돌리기 어렵다

지금 사이트는 GitHub Pages 에 있다. 상용으로 가려면 **새 호스트 · App Check(남이 우리 AI 를
공짜로 못 쓰게) · 주소 이전**이 필요하다. ⚠️ **저장소를 비공개로 바꾸면 Pages 가 죽고 무료
플랜에서는 못 살린다** — 그래서 **새 호스트를 먼저 띄우고** 정리하는 순서가 정해져 있다.

### R8 = **"진짜 사용자처럼 처음부터 끝까지 써 본다"**

로그인 → 문제 넣기 → 편집 → 저장 → AI → 인쇄/한글 → 다시 로그인 → 복구.
⚠️ **실제 아이폰 사파리와 실제 한글 프로그램**에서 확인 못 한 건 따로 남긴다 — 자동 검사가
초록불이라고 "모바일 됨" 이라고 쓰면 안 된다.

### R9 = **"돈 받는 부분"** ⚠️ 해리 결정이 먼저

가격 · 결제사 · 환불 · 약관. 정해지기 전에는 시작할 수 없다.

### R10 = **"내보내도 되나 판정"**

새로 만들지 않는다. 증거가 다 모였는지만 보고 **된다/안 된다**만 답한다.

### C1~C3 = **"AI 비용 재기"** ⚠️ 막혀 있다

제미나이 staging 이 결제 전제를 못 맞춰 실패한다. **해리가 결제를 연결하고 호출을
승인해야** 풀린다. 그래야 C2(실제 토큰·비용 측정) → C3(모델 확정)로 간다.
