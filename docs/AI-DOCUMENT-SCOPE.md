# AI 문서(`document-editor.html`)의 자리 — 화면에서 빼고 코드로 남긴 이유

- 결정: 2026-09-09 · 해리
- 상태: **입구 제거 완료** · 파일·엔진·검사는 그대로

## 무엇을 정했나

`index.html` 에서 **AI 문서로 가는 링크를 없앴다.** 파일(`document-editor.html`)과
조판 엔진(`hwpx-engine.js` · `hwpx-document.js`)은 **지우지 않았다.**

⚠️ **지우는 것과 입구를 빼는 것은 다르다.** 주소로 직접 열면 지금도 동작하고,
`serve.py` 의 `STATIC` 과 `check-document-blocks`·`check-hwpx-browser`·`check-shared-design`
같은 검사도 그대로 돈다.

## 왜

1. **제품의 의의가 흐려졌다.** 이 제품은 *문제집과 모의고사를 만들어 한글로 뽑는 도구*다.
   범용 문서 작성 도구가 라이브러리와 같은 자리에 있으면, 처음 온 사람이 "이게 무슨
   프로그램인가" 를 못 정한다. 상단·레일의 자리는 값비싸다.
2. **원래 기획 의도가 그것이었다.** AI 에게 부탁해 한글로 조판하는 길을 만들고, 그것을
   **모의고사 한글 조판에 응용**하는 것이 목적이었다. 그 목적은 이미 이뤄져 있다 —
   모의고사 한글 내보내기가 같은 엔진(`hwpx-engine.js`)을 쓴다. 별도의 화면은 그
   목적에 필요하지 않았다.
3. **알려진 결함이 있다.** AI 문서에 들어갔다 나오면 로그인이 안 되는 일이 보고됐다
   (`REV-2026-075`). 입구를 빼면 대부분의 사용자는 그 길을 지나지 않는다.
   ⚠️ **그렇다고 결함이 사라지지는 않는다** — 주소로 직접 여는 사람은 여전히 만난다.
   그래서 고친 것이 아니라 **이슈로 남겼다.**

## 무엇이 남아 있나 (지우지 말 것)

| 남긴 것 | 왜 |
|---|---|
| `document-editor.html` | 주소로 열면 동작한다. 나중에 다시 열 수도 있다 |
| `hwpx-engine.js` · `hwpx-document.js` | **모의고사 한글 내보내기가 이 엔진을 쓴다** |
| `serve.py` 의 `STATIC` 항목들 | 빼면 로컬에서 404 로 죽는다 |
| `check-document-blocks.mjs` | 블록 계약 네 곳 대조 — 엔진이 살아 있으면 계약도 살아 있어야 한다 |
| `check-shared-design.mjs` | 두 화면의 디자인 토큰·테마 키 대조 |
| `check-hwpx-browser.mjs` | JS 조판기 ↔ 파이썬 대조 (사본이 갈라지는 것을 막는다) |
| `legal.html` 의 한컴 고지 여섯 곳 중 이 파일 | 저작권 조항이 요구한다 |

`check:static` 이 두 방향을 함께 지킨다 — **index 가 다시 링크하지 않는지**, 그리고
**`serve.py` 에서 파일·엔진이 빠지지 않았는지.** 한쪽만 보면 "입구를 뺀다" 가 어느새
"지운다" 가 된다.
