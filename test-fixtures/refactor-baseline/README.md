# 리팩터링 기준 문제집

이 폴더의 JSON은 사용자 문제집과 분리된 테스트 전용 입력이다. 편집기가 이 파일을
자동으로 불러오거나 저장하지 않는다. 리팩터링 단계마다 각 파일을 별도 새 탭/새 테스트
프로필에서 가져와 편집·미리보기·인쇄가 유지되는지 확인한다.

| 파일 | 확인할 경로 |
| --- | --- |
| `01-math-formulas.json` | 인라인/블록 수식, 선지, 한 쪽 한 문제 |
| `02-korean-passage.json` | 지문 상자, 공유 문항, 보기, 대화문, 표 |
| `03-image-storage.json` | 이미지·정답 이미지 정규화와 렌더링 |
| `04-print-overflow.json` | 긴 문항, 단 배치, 정답 포함/제외 인쇄 |

가져오기 테스트는 기존 사용자의 로컬 문제집을 덮어쓰지 않도록, 전용 브라우저 프로필이나
새 테스트 탭에서만 수행한다. 실제 Firebase Storage 업로드·동기화는 별도의 인증된 테스트
계정에서 확인한다.
